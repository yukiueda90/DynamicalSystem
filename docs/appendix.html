A. 補足: 時間発展 PDE

ここまでに常微分方程式系 \[ \mathbf{x}'=\mathbf{f}(\mathbf{x}), \qquad \mathbf{x}(t)\in\mathbb{R}^d \] によって表される有限次元の連続力学系について解説してきたが, 一方で 熱伝導, 波動, 化学反応, 流体などの空間的な広がりを持つ現象は, しばしば 偏微分方程式 (Partial Differential Equation, PDE) によって記述される. 時間発展 PDE では, 各時刻 $t$ における状態はベクトル $\mathbf{x}(t)\in\mathbb{R}^d$ ではなく \[ u(\cdot,t) \in H \] という, 空間変数 $x$ についての関数 $u(x, t)$ として表される, ここで $H$ は適当な関数空間である. この意味で, 時間発展 PDE は 無限次元力学系 として解釈することができる.

抽象的には, \[ u_t = Au \] あるいは非線形項 $F(u)$ を含めて \[ u_t = Au+F(u) \] のような形で表される時間発展 PDE を考える. ここで $A$ は空間変数についての微分を含む作用素であり, 一般には適切な定義域 $D(A)\subset H$ 上で定義される. 有限次元力学系におけるベクトル場 $\mathbf{f}$ の役割を, PDE ではこのような微分作用素が担っていると考えることができる.

以下では関数解析や偏微分方程式論の詳細には立ち入らず,これまでに学んだ力学系との対応を中心に, 時間発展 PDE の解の挙動を解説する. また, PDE に対する 空間半離散化 により有限次元の常微分方程式系が得られることを確認し, 数値解析との関係についても簡単に紹介する.

A.1: PDE と力学系

最も基本的な例として, 区間 $[0,L]$ 上の一次元 熱方程式 \[ \left\{\begin{array}{rl} u_t &= ku_{xx} \quad \text{in}\quad [0, L],\\ u(0,t) &= u(L,t)=0,\\ u(x,0) &= u_0(x) \end{array}\right. \] を考えよう. ここで $k>0$ は拡散係数であり, \[ u(0,t) = u(L,t)=0 \] は 斉次ディリクレ境界条件 と呼ばれる. 以降, 記号の簡単のために $u_{xx}$ を (空間一次元ではあるが) ラプラシアン (ラプラス作用素) を用いて \[ u_{xx} = \Delta u \] と表記することにする. 特に, 斉次ディリクレ境界条件を満たす関数に対するラプラシアンを ディリクレラプラシアン といい, $\Delta_D$ と表記することがある.

例えば $H=L^2(0,L)$ を相空間として考えれば, 各時刻 $t$ において $u(\cdot,t)\in H$ が一つの状態を表している. 簡単のために $A = k\Delta_D$ とすれば, 熱方程式は \[ u_t = Au \] という無限次元線形力学系とみなすことができる. 有限次元の線形力学系 $\mathbf{x}' = A\mathbf{x}$ では, 行列 $A$ の固有値と固有ベクトルを調べることで解の挙動を説明していたが, 熱方程式においても同様に \[ A\varphi_j = \widetilde{\lambda}_j\varphi_j \] を満たす, 作用素 $A$ の固有値 $\widetilde{\lambda}_j$ と 固有関数 $\varphi_j$ を用いて解の挙動を説明することができる.

まずは $\Delta_D$ の固有値および対応する固有関数を考えてみよう. 境界条件をいったん無視すると, 作用素 $\Delta$ の (複素数値) 固有関数として $e^{\pm iCx}$ を考えることができる. 実際, \[ \Delta e^{\pm iCx} = -C^2 e^{\pm iCx} \] であり、対応する固有値は $-C^2$ である. ここで, 境界条件を考慮するために, \[ Ae^{iCx} + Be^{-iCx} \] という固有関数を考えると, 斉次ディリクレ境界条件を達成する実固有関数を構成するためには \[ A = -\dfrac{i}{2},\quad B = \dfrac{i}{2},\quad C = \dfrac{j\pi}{L} \quad (j = 1, 2, \dots) \] と定めれば良い. つまり, 空間一次元 $[0, L]$ の場合に作用素 $\Delta_D$ の固有値と対応する固有関数は \[ \lambda_j = -\left(\dfrac{j\pi}{L}\right)^2, \qquad \varphi_j(x) = \sin \dfrac{j\pi x}{L} \qquad (j=1, 2, \dots) \] である. ここで, 固有値が全て異なる実数となることが重要である.

上の議論より, 作用素 $A = k\Delta_D$ の固有値および対応する固有関数は \[ \widetilde{\lambda}_j = -k\left(\dfrac{j\pi}{L}\right)^2, \qquad \varphi_j(x) = \sin \dfrac{j\pi x}{L} \qquad (j=1, 2, \dots) \] であり, これを用いると, 空間一次元の熱方程式 $u_t = k\Delta_D u$ の一般解は, 実は 線形常微分方程式系の場合 と同様に \[ u(x,t) = \sum_{j=1}^{\infty}c_j e^{\widetilde{\lambda}_j t}\varphi_n(x) = \sum_{j=1}^{\infty}c_j e^{-k(j\pi/L)^2t} \sin\frac{j\pi x}{L} \] と表すことができる. さらに, 初期値 $u_0(x)$ に対し, \[ u_0(x) = \sum_{j=1}^{\infty}c_j\sin\frac{j\pi x}{L} \] と展開できれば, これら $c_j$ を用いて与えられた初期値 $u_0(x)$ に対する解を得ることもできる. また, 全ての固有値 $\lambda_j$ が負であることに注目すると, やはり有限次元常微分方程式系の場合と同様に, 適切な意味で \[ u(\cdot,t)\longrightarrow0 \qquad (t\to\infty) \] となることもわかる. 以下に, 斉次ディリクレ境界条件下での熱方程式に対する数値計算の様子を掲載する:

一般に, 時間発展 PDE \[ u_t = Au+F(u) \] に対して, 時間に依存しない関数 $u_*(x)$ が \[ Au_*+F(u_*)=0 \] と境界条件を満たすとき, $u_*$ を 定常解 (stationary solution) という. これは常微分方程式系における平衡点に対応する概念であり, 定常解にも安定, 漸近安定, 不安定なものが存在する. 上で熱方程式の解の収束性について言及したが, これは $u_*(x) = 0$ が熱方程式の漸近安定な定常解であることを意味している.

一方, PDE では空間構造を保ったまま移動する解も重要である. 例えば実数直線上の一次元 PDE に対して \[ u(x,t)=\varphi(x-ct) \] という形の解を 進行波解 (traveling wave solution) という. ここで $c$ は波の進行速度を表す. 例えば 反応拡散方程式 \[ u_t=ku_{xx}+f(u) \] に対して \[ u(x,t)=\varphi(\xi), \qquad \xi=x-ct \] とおくと \[ k\varphi''+c\varphi'+f(\varphi)=0 \] という常微分方程式が得られ, さらに $y=\varphi'$ とおくことで \[ \left\{\begin{array}{rl} \varphi'&=y,\\ y'&=-\dfrac{c}{k}y-\dfrac{1}{k}f(\varphi) \end{array}\right. \] という二次元力学系を導出することができる. このように, PDE の進行波解を探す問題は, 二次元連続力学系の軌道を探す問題へ帰着されることがある. これは PDE と有限次元力学系を結びつける代表的な考え方の一つである.

進行波解の代表的な例として, フィッシャー = KPP 方程式 (Fisher-KPP equation) \[ u_t = ku_{xx} + ru(1-u) \quad \text{in}\quad \mathbb{R} \] を考える, ただし $r\gt 0$ はパラメータである. この方程式は, 拡散しながら増殖する個体群などを記述する数理モデルとして利用されるものである. 進行波解 \[ u(x,t)=\varphi(x-ct) \] の存在を仮定し, 関数 $\varphi(\xi)$ に対し $y=\varphi'$ とおくと \[ \mathbf{x}' = \begin{pmatrix} \varphi' \cr y' \end{pmatrix} = \begin{pmatrix} y \cr -\dfrac{c}{k}y-\dfrac{r}{k}\varphi(1-\varphi) \end{pmatrix} \] という二次元力学系を導出することができる. この二次元力学系において, \[ \mathbf{x}_{*1} = \begin{pmatrix} \varphi_{*1} \cr y_{*1} \end{pmatrix} = \mathbf{0},\qquad \mathbf{x}_{*2} = \begin{pmatrix} \varphi_{*2} \cr y_{*2} \end{pmatrix} = \begin{pmatrix} 1 \cr 0 \end{pmatrix} \] は平衡点であり, このことは \[ u_*(x) = \varphi_{*1},\ \varphi_{*2} \] がフィッシャー = KPP 方程式の定常解であることと対応している.

ここでは \[ u(-\infty, t) = \varphi_{*2},\qquad u(\infty, t) = \varphi_{*1} \] となる進行波解が存在するかを考える (このように, 二つの定常状態を単調につなぐ形の進行波解は フロント型進行波解 と呼ばれる). このような進行波解は, 上の二次元力学系において \[ \varphi(-\infty) = \varphi_{*2},\qquad \varphi(\infty) = \varphi_{*1} \] となるような解軌道に対応している. 従って, もしも $\mathbf{x}_{*2}$ から $\mathbf{x}_{*1}$ へ向かうヘテロクリニック軌道が存在すれば, フィッシャー = KPP 方程式の進行波解が存在することになる.

そこで, 上の二次元力学系に対する線形安定性解析を試みる. ヤコビ行列は \[ \begin{pmatrix} 0 & 1 \cr -r/k(1-2\varphi) & -c/k \end{pmatrix} \] であり, この行列に対する固有方程式は \[ \lambda^2 +\dfrac{c}{k} \lambda + \dfrac{r}{k}(1-2\varphi) = 0, \] その解は \[ \lambda = \dfrac{-c\pm \sqrt{c^2-4kr(1-2\varphi)}}{2k} \] である. 従って, $\mathbf{x}_{*2}$ は常に鞍点であり, 一方で $\mathbf{x}_{*1}=\mathbf{0}$ は $4kr \le c^2$ ならば安定なノードである (ただしこれら平衡点の安定性と, 元の PDE の定常解の安定性とは一致しない). また, このとき適切な条件下で $\mathbf{x}_{*2}$ から $\mathbf{x}_{*1}$ へ向かう単調なヘテロクリニック軌道が存在する. 実際, \[ c\ge c_* = 2\sqrt{kr} \] を満たす全ての $c$ に対して, フィッシャー = KPP 方程式の速度が $c$ である進行波解が存在することが知られている.

さて, 有限次元力学系では, 平衡点付近で方程式を線形化して安定性を調べたが, 時間発展 PDE に対しても同様の考え方により, 定常解の安定性を調べることができる. 例として, 上と同様に反応拡散方程式 \[ u_t=k\Delta_D u + f(u) \] を考える. 定常解 $u_*(x)$ は \[ k\Delta_D u_* + f(u_*)=0 \] を満たすことに注意. 定常解の近くの解を \[ u(x,t) = u_*(x)+v(x,t) \] と表すとき, $v$ が十分小さいならば \[ f(u_*+v) = f(u_*) + f'(u_*)v + \text{高次の項} \] とみなすことができ, 高次の項は十分小さいと思って無視すると \[ \begin{array}{rl} v_t &= u_t \cr &= \underbrace{k\Delta_D u_* + f(u_*)}_{=0} + k\Delta_D v + f'(u_*)v \cr &= k\Delta_D v + f'(u_*)v \end{array} \] という PDE が得られる. この PDE の右辺を $Lv$ とおくと, $L$ は線形作用素であり, 従って上の $v$ についての PDE は \[ v_t = Lv \] という線形化方程式である. これは非線形の常微分方程式系において \[ \mathbf{x}' = D\mathbf{f}(\mathbf{x}_*)\mathbf{x} \] を考えたことに対応するアイデアであり, やはり同様に作用素 $L$ の固有値を調べることで線形安定性解析が可能である.

さらに局所的な安定性だけでなく, PDE の長時間挙動についても力学系的な考え方を利用することができる. ここでは詳細は説明しないが, 例えば 極限集合, アトラクター, 不変集合, 分岐 などの概念は, 時間発展 PDE に対しても導入することができる.

ここでは例として アレン=カーン方程式 (Allen-Cahn equation) \[ u_t = \varepsilon^2 \Delta u + \gamma u(1-u^2) \] を考える, ここで $\varepsilon\gt0$ と $\gamma\gt 0$ はパラメータである. この反応拡散方程式は, 相転移や界面現象を記述する数理モデルとして扱われる. ここでは簡単のために空間 $1$ 次元の場合のみを考え, また斉次ディリクレ境界条件を課すことにする: \[ \left\{\begin{array}{rl} u_t &= \varepsilon^2 \Delta u + \gamma u(1-u^2) \quad \text{in}\quad [0, L], \cr u(0, t) &= u(L, t) = 0, \cr u(x, 0) &= u_0(x). \end{array}\right. \] まずは数値計算結果の様子を確認してみよう:

いま, アレン=カーン方程式 \[ u_t = \varepsilon^2 \Delta_D u + \gamma u(1-u^2) \quad \text{in}\quad [0, L] \] において, $u_*(x) = 0$ は定常解の一つである. また, $\gamma=0$ とすると第 $1$ 項のみが残り, 方程式は熱方程式となる. しかし, 上の数値計算では, 適当なパラメータ $\gamma\gt 0$ に対し, $u_*=0$ でない漸近安定な定常解の存在を示唆している. このことは, パラメータ $\gamma$ を大きくすることで分岐が起こり, 非自明な定常解が現れるためと予想することができる.

アレン=カーン方程式の分岐について解析的に確かめてみよう. まず, 定常解 $u_*(x)$ は \[ 0 = \Delta_D u_* + \dfrac{\gamma}{\varepsilon^2}u_*(1-u_*^2)\quad \text{in}\quad [0, L] \] を満たしていることから, $\lambda = \gamma/\varepsilon^2$ の値に注目して定常解の安定性を考えてみる. 自明な定常解 $u_*=0$ については, 線形安定性解析より \[ v_t = \Delta_D v + \lambda v \quad \text{in} \quad [0, L] \] を考えれば良いことになる ($u_*$ が十分 $0$ に近ければ $u_*^3$ は無視してしまってもよいだろう, ということに相当している). ここで, $Lv = \Delta_D v + \lambda v$ により定義される線形作用素 $L$ の固有値 $\lambda_j$ と固有関数 $\varphi_j(x)$ を考えると \[ \varphi_j(x) = \sin\dfrac{j\pi}{L}x,\quad \lambda_j = \lambda - (j\pi/L)^2\qquad (j=1, 2, \dots) \] である. 特に最大固有値は $\lambda_1 = \lambda - (\pi/L)^2$ であり, これが負ならば定常解 $u_* = 0$ は安定であり, 正ならば不安定である. 実は, $\lambda = (\pi/L)^2$ において超臨界ピッチフォーク分岐が起こり, 定常解 $0$ は安定から不安定に転じ, $0$ でない安定な定常解が生じる. さらに $j=2, 3, \dots$ に対し, $\lambda = (j\pi/L)^2$ でも (定常解 $u_* = 0$ における不安定多様体の次元が増加し) ピッチフォーク状の分岐が起こる. 結果的に, $\lambda = \gamma/\varepsilon^2$ が十分に大きければ, 大量の分岐により生じた大量の定常解が存在することになる.

また, エネルギー $E(u)$ が存在し, \[ \frac{d}{dt}E(u(t))\le0 \] となるような PDE に対し, このエネルギーは有限次元力学系におけるリアプノフ関数と同様に, 解の長時間挙動を調べるための重要なアイデアとなる. 例えば熱方程式では \[ E(u) = \dfrac{1}{2}\int_0^L u(x)^2~dx \] とおくと, 斉次ディリクレ境界条件下で \[ \begin{array}{rl} \dfrac{d}{dt}E(u(t)) &= \displaystyle\int_0^L u u_t~dx \cr &= k\displaystyle\int_0^L u u_{xx}~dx \cr &= -k\displaystyle\int_0^L |u_x|^2~dx \le0 \end{array} \] が成立するため, 熱方程式では時間とともにエネルギーが単調減少することがわかる. これは, 熱方程式の定常解 $u_*(x) = 0$ が漸近安定であることと密接に関連している.

A.2: 時間発展 PDE の離散化

ここまでに, 時間発展 PDE を無限次元力学系として捉えるアイデアを解説した. また, いくつかの例に対して数値計算結果を示したが, 時間発展 PDE の数値計算を行うためには, 時間だけでなく空間も離散化することで自由度有限の問題に置き換える必要がある. 古典的な差分法の議論では, 時間と空間を一度に離散化することもあるが, ここでは 空間半離散化 により時間発展 PDE を有限次元の常微分方程式系により近似し, さらに時間離散化を適用する手順をまとめる. さらに, これに関連する数値解析の議論について簡単に紹介する.

まずは例として, 斉次ディリクレ境界条件下の空間一次元熱方程式 \[ u_t = k\Delta_D u \qquad \text{in}\quad [0, L] \] を考える. 先ほど紹介したように, $u_*(x) = 0$ が漸近安定な定常解である.

ここでは空間半離散化に 中心二階差分 を利用する: まず, 区間 $[0, L]$ を $M$ 等分することで空間分割幅を $h = L/M\gt0$ とし, また $x_m = mh$ と定める. このとき, 関数 $u(x)$ に対し, \[ \Delta u(x_m) \approx \dfrac{\dfrac{u(x_{m+1}) - u(x_m)}{h} - \dfrac{u(x_m) - u(x_{m-1})}{h}}{h} = \dfrac{u(x_{m+1}) - 2u(x_m) + u(x_{m-1})}{h^2} \] と近似する. なお, テイラーの定理を用いると, 関数 $u$ が $C^4$ 級ならば \[ \Delta u(x_m) = \dfrac{u(x_{m+1}) - 2u(x_m) + u(x_{m-1})}{h^2} + O(h^2) \] であることがわかる.

これを熱方程式の空間半離散化に応用する場合には, 熱方程式の解 $u$ に対し, $u_m(t) \approx u(x_m, t)$ なる関数 $u_m(t)$ を \[ (u_m)_t = k \dfrac{u_{m+1} - 2u_m + u_{m-1}}{h^2} \qquad (m = 1, 2, \dots, M-1) \] により定めれば良い, ただし斉次ディリクレ境界条件より $u_0(t) = u_M(t) = 0$ であるとする. さて, この式は第 $m$ 成分が $u_m$ であるベクトル $\mathbf{u}$ を用いて \[ \mathbf{u}_t = \begin{pmatrix} (u_1)_t \cr (u_2)_t \cr (u_3)_t \cr \vdots \cr (u_{M-1})_t \end{pmatrix} = k\dfrac{1}{h^2}\begin{pmatrix} -2u_1 + u_2 \cr u_1 - 2u_2 + u_3 \cr u_2 - 2u_3 + u_4 \cr \vdots \cr u_{M-2} - 2u_{M-1} \end{pmatrix} = k\underbrace{\dfrac{1}{h^2}\begin{pmatrix} -2 & 1 & 0 & \dots & 0 \cr 1 & -2 & 1 & \dots & 0 \cr 0 & 1 & -2 & \dots & 0 \cr \vdots & \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & 0 &\dots & -2 \end{pmatrix}}_{=L_h}\underbrace{\begin{pmatrix} u_1 \cr u_2 \cr u_3 \cr \vdots \cr u_{M-1} \end{pmatrix}}_{=\mathbf{u}} = kL_h \mathbf{u} \] と表すことができる. つまり, 熱方程式 \[ u_t = k\Delta_D u\quad\text{in}\quad [0, L] \] に対する空間半離散化により, 常微分方程式系として表される線形力学系 \[ \mathbf{u}_t = kL_h \mathbf{u} \] を導出することができたことになる. なお, 行列 \[ L_h = \dfrac{1}{h^2}\begin{pmatrix} -2 & 1 & 0 & \dots & 0 \cr 1 & -2 & 1 & \dots & 0 \cr 0 & 1 & -2 & \dots & 0 \cr \vdots & \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & 0 &\dots & -2 \end{pmatrix} \in \mathbb{R}^{(M-1)\times (M-1)} \] を (斉次ディリクレ境界条件下での) 離散ラプラシアン (もしくは 離散ラプラシアン行列) と呼ぶことがある. 実際には, 熱方程式に対する中心二階差分に限らず, 一般に時間発展 PDE の空間半離散化により有限次元の常微分方程式系を導出することができる. このようなアイデアは method of lines と総称されることがある.

さて, 上のように導出された有限次元の常微分方程式系の解は, 元の時間発展 PDE の解の近似となっていることが望ましい. ここでは, 熱方程式に対して $u_*(x) = 0$ が漸近安定な定常解であることの近似として, 線形力学系 $\mathbf{u}' = kL_h\mathbf{u}$ に対して $\mathbf{u}=\mathbf{0}$ が漸近安定な平衡点となっているかを確認してみよう. このためには, 離散ラプラシアン $L_h$ の固有値を調べれば良い.

まず, 連続ラプラシアンのときと同様に, 境界条件をいったん無視して中心二階差分作用素 $\delta_h^{(2)}$ を考える: ベクトル \[ \mathbf{v} = \begin{pmatrix} v_0 \cr v_1 \cr \vdots \cr v_M \end{pmatrix} \] に対し, \[ \delta_h^{(2)}v_m = \dfrac{v_{m+1} - 2v_m + v_{m-1}}{h^2} \qquad (m=1, 2,\dots M-1) \] とする. このとき, 虚数単位 $i=\sqrt{-1}$ を用いて (連続ラプラシアンの複素固有関数のアナロジーとして) \[ v_m = e^{\pm i\theta m} \] としてみると, \[ \begin{array}{rl} \delta_h^{(2)}v_m &= \dfrac{e^{\pm i\theta(m+1)} -2e^{\pm i\theta m} + e^{\pm i\theta(m-1)}}{h^2} \cr &= \dfrac{e^{i\theta} + e^{-i\theta} -2}{h^2}e^{\pm i\theta m} \cr &= \dfrac{2\cos\theta-2}{h^2}e^{\pm i\theta m} \cr &= \underbrace{\left(-\dfrac{4}{h^2}\sin^2\dfrac{\theta}{2}\right)}_{=\lambda}v_m \end{array} \] が得られる. あとは, 境界条件を考慮するために第 $m$ 成分が \[ v_m = Ae^{i\theta m} + Be^{-i\theta m} \] であるベクトル $\mathbf{v}$ を考えると, "斉次ディリクレ境界条件" $v_0 = v_M = 0$ を達成する実固有ベクトルを構成するためには \[ A = -\dfrac{i}{2},\quad B = \dfrac{i}{2},\quad \theta = \dfrac{j\pi}{M} = \dfrac{j\pi h}{L}\quad (j=1, 2, \dots, M-1) \] と定めれば良い. 結果的に, 斉次ディリクレ境界条件下での離散ラプラシアン $L_h\in\mathbb{R}^{(M-1)\times (M-1)}$ の固有値および固有ベクトルは \[ \lambda_j = -\dfrac{4}{h^2}\sin^2\dfrac{j\pi}{2M},\qquad \mathbf{v}_j = \begin{pmatrix} \sin \dfrac{j\pi x_1}{L} \cr \vdots \cr \sin \dfrac{j\pi x_{M-1}}{L} \end{pmatrix} \in\mathbb{R}^{M-1}\qquad (j=1, 2, \dots, M-1) \] となる (これは連続ラプラシアン $\Delta_D$ の固有値, 固有関数が \[ \lambda_j = -\left(\dfrac{j\pi}{L}\right)^2, \qquad \varphi_j(x) = \sin \dfrac{j\pi x}{L} \qquad (j=1, 2, \dots) \] となることと対応している, 実際 $M$ が十分大きければ \[ -\dfrac{4}{h^2}\sin^2\dfrac{j\pi}{2M} \approx -\dfrac{4}{h^2}\left(\dfrac{j\pi}{2M}\right)^2 = -\left(\dfrac{j\pi}{L}\right)^2 \] である). 特に, 離散ラプラシアン $L_h\in\mathbb{R}^{(M-1)\times (M-1)}$ の全ての固有値 (の実部) が負であることから, 線形力学系 $\mathbf{u}' = kL_h\mathbf{u}$ に対し平衡点 $\mathbf{0}$ は漸近安定である. これは元の熱方程式の性質を適切に再現していると判断できる.

このように, 空間半離散化により熱方程式の性質を再現する常微分方程式系を導出できたため, あとはこの線形力学系に対し適当な数値計算手法を適用すれば数値計算が実行可能である. ここでは前進オイラー法を用いてみよう: 時間刻み幅 $\tau \gt0$ を定め, また $t_n = n\tau$ とする. このとき, 与えられた $\mathbf{u}^n \approx \mathbf{u}(t_n)$ に対し, \[ \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau} = kL_h\mathbf{u}^n \] つまり \[ \mathbf{u}^{n+1} = (I + k\tau L_h)\mathbf{u}^n \] という離散力学系の解を計算すれば良い ($\mathbf{u}^0$ は初期条件から与える). なお, 時間発展 PDE に対して空間半離散化と時間離散化を適用することを 全離散化 と呼ぶことがある.

ここで, $L_h$ の固有値 $\lambda_j$, 固有ベクトル $\mathbf{v}_j$ を用いると, 行列 $I + k\tau L_h$ の固有値は \[ \widetilde{\lambda}_j = 1-\dfrac{4k\tau}{h^2}\sin^2\dfrac{j\pi}{2M} \qquad (j=1, 2, \dots, M-1) \] である. いま, 上の離散力学系の平衡点 $\mathbf{0}$ が漸近安定となるためには, \[ |\widetilde{\lambda}_j| \lt 1 \] でなければならず, これは無条件には成立しない. 空間半離散化に続いて時間離散化も適用することで導出された離散力学系が, 元の PDE と同様の性質を再現するためには, 時間刻み幅などに適切な条件を課す必要がある.

実際, もしも $\widetilde{\lambda}_j$ たちの中に, $|\widetilde{\lambda}_i|\gt 1$ となるものが存在すると, \[ (I+k\tau L_h)^n\mathbf{e} \to \infty \quad\mbox{as}\quad n\to\infty \] となるベクトル $\mathbf{e}$ が存在してしまうことになる. 実際の数値計算の際には, コンピュータ内部で数値を浮動小数点数として扱う際の丸め誤差が発生するが, そうした誤差の影響が増幅されてしまう恐れがある. 例えば空間分割幅や時間刻み幅の選び方次第では, 以下のような数値計算結果が得られてしまうこともある:

なお, 大雑把には初期値の摂動や丸め誤差, 打ち切り誤差などの影響が計算中に過度に増幅されない場合, 数値計算手法は安定 (もしくは 数値的に安定) であるといい, 一方で誤算などの影響が増幅される場合, 数値計算手法は不安定であるという (数値計算手法の安定性は 数値安定性 と言及される). 熱方程式の場合は単に数値的に安定であるという以上に, 離散力学系として解釈した際の平衡点 $\mathbf{0}$ が漸近安定であること, つまり $|\widetilde{\lambda}_j|\lt 1$ が満たされることが望ましいだろう.

A.3: 数値安定性と誤差解析

上では熱方程式の全離散化を離散力学系と解釈したが, 一般の時間発展 PDE は漸近安定な定常解を持つとは限らず, 従って全離散化を離散力学系と解釈して性質の再現性を調べるという方法がいつでも機能するとは限らない. 一方で, 数値安定性は (実際には数値安定性と呼ばれる概念は様々であるが) 多くの場合には不等式評価を用いて比較的容易に判断することができる. ここでは, 数値安定性を判断するための不等式の導出と, これと 残差 が十分小さいという性質 (整合性) から誤差の不等式評価を導出できることを紹介する.

まず, 例として斉次ディリクレ境界条件下で空間一次元の熱方程式 \[ u_t = k\Delta_D u \] を考えてみよう. 中心二階差分による空間半離散化により, \[ \mathbf{u}_t = kL_h\mathbf{u} \] という常微分方程式系が導出されるのであった. さらにここでは, 時間離散化に後退オイラー法を用いてみる: \[ \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau} = kL_h\mathbf{u}^{n+1} \] これについて考えるために, 離散ラプラシアン \[ L_h = \dfrac{1}{h^2}\begin{pmatrix} -2 & 1 & 0 & \dots & 0 \cr 1 & -2 & 1 & \dots & 0 \cr 0 & 1 & -2 & \dots & 0 \cr \vdots & \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & 0 &\dots & -2 \end{pmatrix} \in \mathbb{R}^{(M-1)\times (M-1)} \] の性質を調べるアイデアを準備しておこう:

ベクトル $\mathbf{v}, \mathbf{w}\in\mathbb{R}^{M-1}$ に対し, \[ (\mathbf{v}, \mathbf{w})_h = h\sum_{m=1}^{M-1}v_mw_m = h\mathbf{v}^{\operatorname{T}}\mathbf{w}\qquad \|\mathbf{v}\|_h = \sqrt{h\sum_{m=1}^{M-1}v_m^2} = \sqrt{(\mathbf{v}, \mathbf{v})_h} \] をそれぞれ (斉次ディリクレ境界条件下での) 離散 $L^2$ 内積, 離散 $L^2$ ノルム という.

ベクトル $\mathbf{v}, \mathbf{w}\in\mathbb{R}^{M-1}$ に対する離散 $L^2$ 内積, 離散 $L^2$ ノルムは, \[ v_h(x_m) = v_m,\quad w_h(x_m) = w_m \qquad (m=0, 1, \dots M) \] を満たす関数に対する (通常の) $L^2$ ノルム, $L^2$ 内積に現れる積分を台形則で近似したものになっている. ただし $v_0 = v_M = 0$ などと定める (これは斉次ディリクレ境界条件のためであり, 異なる境界条件を考える際には異なる離散 $L^2$ 内積, 離散 $L^2$ ノルムが用いられる場合がある).

また, これと関連して, ベクトル $\widetilde{\mathbf{v}}, \widetilde{\mathbf{w}}\in\mathbb{R}^M$ に対して \[ (\widetilde{\mathbf{v}}, \widetilde{\mathbf{w}})_e = h\sum_{m=1}^{M}\widetilde{v}_m\widetilde{w}_m \qquad \|\widetilde{\mathbf{v}}\|_e = \sqrt{h\sum_{m=1}^{M}\widetilde{v}_m^2} = \sqrt{(\widetilde{\mathbf{v}}, \widetilde{\mathbf{v}})_e} \] と表記することにする. さらに, 離散ラプラシアンと関連する行列として, \[ G_h = \dfrac{1}{h}\begin{pmatrix} 1 & 0 & 0 & \dots & 0 \cr -1 & 1 & 0 & \dots & 0 \cr 0 & -1 & 1 & \dots & 0 \cr \vdots & \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & 0 & \dots & -1 \end{pmatrix} \in\mathbb{R}^{M\times(M-1)} \] と定める (これを斉次ディリクレ境界条件下の 離散勾配 もしくは 離散勾配行列 と呼ぶことがある). この行列は \[ -L_h = G_h^{\operatorname{T}}G_h \] を満たすため, 任意の $\mathbf{v}, \mathbf{w}\in\mathbb{R}^{M-1}$ に対し, \[ \begin{array}{rl} (-L_h\mathbf{v}, \mathbf{w})_h &= h(G_h^{\operatorname{T}}G_h\mathbf{v})^{\operatorname{T}}\mathbf{w} \cr &= h(G_h\mathbf{v})G_h\mathbf{w} = (G_h\mathbf{v}, G_h\mathbf{w})_e \end{array} \] を満たす. これは斉次ディリクレ境界条件下での部分積分 \[ \int_0^L (-v_{xx})w~dx = \int_0^Lv_xw_x~dx \] に相当する性質である.

これを用いると, 熱方程式に対する後退オイラー法 \[ \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau} = kL_h\mathbf{u}^{n+1} \] に対し, \[ \begin{array}{rl} -k\tau\|G_h\mathbf{u}^{n+1}\|_e^2 &= k\tau(L_h\mathbf{u}^{n+1}, \mathbf{u}^{n+1})_h \cr &= (\mathbf{u}^{n+1}-\mathbf{u}^n, \mathbf{u}^{n+1})_h \cr &= \dfrac{1}{2}\left(\mathbf{u}^{n+1}-\mathbf{u}^n, (\mathbf{u}^{n+1}-\mathbf{u}^n) + (\mathbf{u}^{n+1}+\mathbf{u}^n)\right)_h \cr &= \dfrac{1}{2}\left(\|\mathbf{u}^{n+1}-\mathbf{u}^n\|_h^2 + \|\mathbf{u}^{n+1}\|_h^2 - \|\mathbf{u}^n\|_h^2\right) \end{array} \] となるため, ここから \[ \|\mathbf{u}^{n+1}\|_h^2 - \|\mathbf{u}^n\|_h^2 = -2k\tau\|G_h\mathbf{u}^{n+1}\|_e^2 - \|\mathbf{u}^{n+1}-\mathbf{u}^n\|_h^2 \le 0 \] が得られ, 従って \[ \|\mathbf{u}^{n+1}\|_h^2 \le \|\mathbf{u}^n\|_h^2 \le \dots \le \|\mathbf{u}^0\|_h^2 \] となる. つまり, 後退オイラー法により得られる時刻 $n$ ステップ目の近似解 $\mathbf{u}^n$ について, その離散 $L^2$ ノルムは初期値にのみ依存する量で必ず上から抑えることができる. 同様に初期値の摂動の影響を抑えることができ, また丸め誤差の影響も (蓄積する可能性はあるが) 過度に増幅されるようなことが起こり得ないことを意味しているため, 後退オイラー法の数値安定性はこの不等式により保証されることになる.

同様のアイデアに基づき, 熱方程式の厳密解と後退オイラー法による近似解の誤差に対する不等式評価も解説しよう. まずは必要な準備をしておく:

$H$ をヒルベルト空間とする. このとき, \[ |(v, w)_H| \le \|v\|_H\|w\|_H \quad\text{for all}\quad v, w\in H \] が成立する.

さて, 厳密解 $u(x, t)$ の $x_m$ 上での値をベクトルとして取り出すために, \[ R_hu = \begin{pmatrix} u(x_1, t) \cr \vdots \cr u(x_{M-1}, t) \end{pmatrix} \] と定める. また, 空間半離散化により得られる常微分方程式系の解 $\mathbf{u}(t)$ に対して, 空間半離散化による誤差を \[ \mathbf{e}_h(t) = R_hu(t) - \mathbf{u}(t) \] と定める. さらに時間について後退オイラー法を用いることで得られる近似解 $\mathbf{u}^n$ に対して, 時間離散化による誤差を \[ \mathbf{e}_{\tau}^n = \mathbf{u}(t_n) - \mathbf{u}^n \] と定める. これらを用いて, \[ R_hu(t_n) - \mathbf{u}^n = \mathbf{e}_h(t_n) + \mathbf{e}_{\tau}^n \] の適当なノルムに対する不等式評価を与えよう.

まず, 空間半離散化から考える. 空間半離散化により導出される式 \[ \mathbf{u}_t = kL_h\mathbf{u} \] に, 代わりに厳密解 $u$ を代入すると, 左辺と右辺は一致しない (このとき, 両辺の差のことを 残差 という). 具体的には, \[ \left\{\begin{array}{cl} (R_hu)_t - kL_h (R_hu) &= \mathbf{r}_h \cr \mathbf{u}_t - kL_h\mathbf{u} &= \mathbf{0} \end{array}\right. \] となっており, 残差ベクトル $\mathbf{r}_h\neq\mathbf{0}$ の各成分は \[ \begin{array}{rl} (\mathbf{r}_h)_m &= u_t(x_m, t) - k\delta_h^{(2)}u(x_m, t) \cr &= k\Delta u(x_m, t) - k\dfrac{u(x_{m+1}, t) - 2u(x_m, t) + u(x_{m-1}, t)}{h^2} \end{array} \] であるため, 厳密解 $u$ が十分滑らかかつ必要な導関数が一様有界ならば $\|\mathbf{r}_h\|_h \le Ch^2$ である. また, 上の二つの式の差を取ることで \[ \dfrac{d}{dt}\mathbf{e}_h - kL_h\mathbf{e}_h = \mathbf{r}_h \] という, 誤差 $\mathbf{e}_h(t)$ が満たす式を導出することができる (これは 誤差方程式 と呼ばれることがある). この式の両辺に $\mathbf{e}_h$ との離散 $L^2$ 内積を考えると, \[ \dfrac{1}{2}\dfrac{d}{dt}\|\mathbf{e}_h\|_h^2 + k\|G_h\mathbf{e}_h\|_e^2 = (\mathbf{r}_h, \mathbf{e}_h)_h \] が得られ, さらに式変形すると \[ \dfrac{1}{2}\dfrac{d}{dt}\|\mathbf{e}_h\|_h^2 \le \|\mathbf{r}_h\|_h\|\mathbf{e}_h\|_h \] となる. 両辺を $\|\mathbf{e}_h\|_h\gt 0$ のとき形式的に割ることで \[ \dfrac{d}{dt}\|\mathbf{e}_h\|_h \le \|\mathbf{r}_h\|_h \] となるので, これを積分することで \[ \|\mathbf{e}_h(t)\|_h - \|\mathbf{e}_h(0)\|_h \le \int_0^t\|\mathbf{r}_h(s)\|_h~ds \le Cth^2 \] が得られる. いま, $\mathbf{e}_h(0)=\mathbf{0}$ となるように初期値を設定すれば, $\mathbf{e}_h(t)$ に関する不等式評価が得られることになる.

次に時間離散化誤差を評価しよう. 上と同様に \[ \left\{\begin{array}{cl} \dfrac{\mathbf{u}(t_{n+1}) - \mathbf{u}(t_n)}{\tau} - kL_h\mathbf{u}(t_{n+1}) &= \mathbf{r}_{\tau}^{n+1}, \cr \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau} - kL_h\mathbf{u}^{n+1} &= \mathbf{0} \end{array}\right. \] であり, 時間離散化に関する残差ベクトル $\mathbf{r}_{\tau}^{n+1}$ の各成分は後退オイラー法の誤差から来ているため \[ \|\mathbf{r}_{\tau}^{n+1}\|_h \le C\tau \] である. 時間離散化の誤差方程式 \[ \dfrac{\mathbf{e}_{\tau}^{n+1} - \mathbf{e}_{\tau}^n}{\tau} - k L_h\mathbf{e}_{\tau}^{n+1} = \mathbf{r}_{\tau}^{n+1} \] を整理すると \[ \mathbf{e}_{\tau}^{n+1} = (I-k\tau L_h)^{-1}(\mathbf{e}_{\tau}^n + \tau\mathbf{r}_{\tau}^{n+1}) \] であり, $I-k\tau L_h$ の固有値は ($L_h$ の固有値に関する議論から) すべて $1$ 以上であることがわかるため, \[ \|\mathbf{e}_{\tau}^{n+1}\|_h \le \|\mathbf{e}_{\tau}^n + \tau\mathbf{r}_{\tau}^{n+1}\|_h\le \|\mathbf{e}_{\tau}^n\|_h + \tau\|\mathbf{r}_{\tau}^{n+1}\|_h \] であり, これを繰り返すことで \[ \|\mathbf{e}_{\tau}^n\|_h \le \|\mathbf{e}_{\tau}^0\|_h + \underbrace{\sum_{j=1}^n\tau\|\mathbf{r}_{\tau}^j\|_h}_{\le Ct_n\tau} \] が得られる. いま, $\mathbf{e}_{\tau}^0=\mathbf{0}$ となるように初期値を設定すれば良い.

以上をまとめると, \[ \begin{array}{rl} \|R_hu(t_n) - \mathbf{u}^n\|_h &\le \|\mathbf{e}_h(t_n)\|_h + \|\mathbf{e}_{\tau}^n\|_h \cr &\le Ct_nh^2 + Ct_n\tau \cr &\le Ct_n(h^2+\tau) \end{array} \] という不等式評価が得られたことになる. 右辺が $t_n$ に依存するため, 時間ステップ数 $n$ が大きくなるほどに誤差が大きくなる恐れがあることは確かだが, 誤差の収束オーダーとしては空間中心二階差分に由来する $O(h^2)$ と, 時間後退オイラー法に由来する $O(\tau)$ がそのまま現れていることがわかる.

熱方程式では拡散項以外に制御すべき項がないため, 非常に単純な誤差評価が得られる. 一方で, 反応項などを含む場合には, その項による誤差の増幅も評価する必要がある. 例えば反応拡散方程式 \[ u_t = k\Delta_D u + f(u) \] に対して, 上と同様の評価を試みる. 簡単のために $f$ はリプシッツ連続であると仮定し, $L$ をリプシップ定数とすると, 空間半離散化の誤差方程式から (関数 $f$ の値を各成分に対応させる関数も $f$ と表記することにすると) \[ \dfrac{1}{2}\dfrac{d}{dt}\|\mathbf{e}_h\|_h^2 + k\|G_h\mathbf{e}_h\|_e^2 - (f(R_hu)-f(\mathbf{u}), \mathbf{e}_h)_h = (\mathbf{r}_h, \mathbf{e}_h)_h \] が得られ, これを式変形することで ($f$ に単調性や散逸性などを仮定しない限り) \[ \dfrac{d}{dt}\|\mathbf{e}_h\|_h \le L\|\mathbf{e}_h\|_h + \|\mathbf{r}_h\|_h \] のようになり, Grönwall の不等式より \[ \|\mathbf{e}_h(t)\|_h \le e^{Lt}\left(\|\mathbf{e}_h(0)\|_h + \int_0^t e^{-Ls}\|\mathbf{r}_h\|_h~ds\right) \le C(e^{Lt}-1)h^2 \] のような不等式評価となる (ただし $\mathbf{e}_h(0) = \mathbf{0}$ とした).

さらに時間離散化の誤差方程式から \[ \|\mathbf{e}_{\tau}^{n+1}\|_h \le \|\mathbf{e}_{\tau}^n\|_h + L\tau \|\mathbf{e}_{\tau}^{n+1}\|_h + \tau\|\mathbf{r}_{\tau}^{n+1}\|_h \] となるため, 十分小さい $\tau\gt 0$ に対して $1/(1-L\tau) \le e^{L\tau}$ であることに注意すると \[ \|\mathbf{e}_{\tau}^{n+1}\|_h \le e^{L\tau}\left(\|\mathbf{e}_{\tau}^n\|_h + \tau\|\mathbf{r}_{\tau}^{n+1}\|_h\right) \] が得られる. これを繰り返すことで, \[ \|\mathbf{e}_{\tau}^n\|_h \le e^{Lt_n}\left(\|\mathbf{e}_{\tau}^0\|_h + \tau\sum_{k=0}^{n-1}\|\mathbf{r}_{\tau}^{k+1}\|_h\right) \le Ct_ne^{Lt_n}\tau \] のような不等式評価となる (ただし $\mathbf{e}_{\tau}^0 = \mathbf{0}$ とした). 以上のように, 右辺の項の性質次第では非線形項による誤差の増幅を, 例えば指数関数を用いることでしか上から抑えられない, ということも起こり得る. 従って, 多くの場合に数値計算の誤差は, 対象とする方程式の性質に強く依存することになり, 個々の方程式に対する数値解析の議論が必要となるのである.

なお, 上では反応拡散方程式の空間半離散化の誤差評価において Grönwall の不等式を利用したが, 同様に時間離散化の誤差評価に利用した不等式は, 以下に述べる 離散 Grönwall の不等式 と対応するものであり, このような "離散版" の定理は数値解析の様々な場面で利用される:

非負の実数列 $\{x_n\}$, $\{a_n\}$ および $\{c_n\}$ に対し, \[ x_{n+1} \le x_0 + \displaystyle\sum_{k=0}^{n}a_kx_k + \sum_{k=0}^{n}c_k \quad\text{for all}\quad n\ge 0 \implies x_n \le \left(x_0 + \sum_{k=0}^{n-1}c_k\right)\exp\left(\sum_{k=0}^{n-1}a_k\right) \] が成立する.

$n\in\mathbb{N}$ を固定し \[ C_n = x_0 + \sum_{k=0}^{n-1}c_k,\qquad y_0 = C_n,\qquad y_j = \sum_{k=0}^{j-1}a_kx_k + C_n \quad (j=1,\dots, n) \] とおく. すると定理の仮定より $x_j \le y_j\ \ (j=0, 1, \dots, n$) であり, 従って \[ y_{j+1} = y_j + a_jx_j \le (1+a_j)y_j \] となるため, $1+a_k \le e^{a_k}$ を用いて \[ x_n\le y_n \le y_0\prod_{k=0}^{n-1}(1+a_k) \le C_n\exp\left(\sum_{k=0}^{n-1}a_k\right) \le \left(x_0 + \sum_{k=0}^{n-1}c_k\right)\exp\left(\sum_{k=0}^{n-1}a_k\right) \] という不等式が得られる.

A.4: スペクトル法

ここまでに, 離散化の方法として微分を差分商で置き換えるというものを紹介してきたが, このような手法は 差分法 と総称される. 離散化の方法には差分法以外にも様々なものが存在するが, ここでは解を大域的な基底関数の線型結合で近似する スペクトル法 による空間半離散化を紹介し, その実装や応用について紹介する.

スペクトル法の説明の前に, 準備としてまずは 離散フーリエ変換 について解説しよう. 離散フーリエ変換は通常のフーリエ変換の "離散版" に相当するものであり, スペクトル法において重要な役割を果たす. また差分法や信号処理などに応用することもできる, 強力なテクニックである.

ここでは区間 $[0, L]$ 上で定義された適切な $L$-周期関数 $u(x)$ を考える. まず, 通常の (複素) フーリエ級数展開は, フーリエ係数 \[ \widehat{u}_m = \dfrac{1}{L}\int_0^L u(x)e^{-2\pi i mx/L}~dx \qquad (m\in\mathbb{Z}) \] を用いて \[ u(x) = \sum_{k=-\infty}^{\infty}\widehat{u}_k e^{2\pi i kx/L} \] である. フーリエ係数は各フーリエモードの周波数成分を表しているため, フーリエ級数展開は連続な関数 $u(x)$ として与えられたデータを周波数成分に分解していると解釈できる.

一方で, 離散フーリエ変換では周期的なデータが有限個の点の上で (離散的なデータとして) 与えられている状況を考える. 例えば 区間 $[0, L]$ を $M$ 等分し, $h=L/M$, $x_m = mh$ とおき, 点 $x_m$ に対応するデータ $u_m$ が与えられているとする, ただし $M$ は偶数であるとし, また $u_0 = u_M$ とする. このとき (フーリエ係数を求める積分を台形則で近似した), \[ \widehat{u}_m = \dfrac{h}{L}\sum_{k=0}^{M-1}u_ke^{-2\pi imx_k/L}\qquad (m=0, 1, \dots M-1) \] を 離散フーリエ変換 といい, \[ u_m = \sum_{k=0}^{M-1}\widehat{u}_k e^{2\pi ikx_m/L}\qquad (m=0, 1, \dots M-1) \] を 離散フーリエ逆変換 という. これは離散的なデータを離散的な周波数成分に分解していると解釈できる. なお, $M$ が偶数であることから, $m$ たちの後半 \[ m = M/2 + 1, \dots, M-1 \] は, \[ m = -M/2 + 1, \dots, -1 \] という負の周波数に対応していることに注意.

さて, ここでは離散フーリエ変換を行列ベクトル積の形で記述することにする. 記号の簡単のために, \[ \omega = e^{-2\pi i/M} \] とおくと, 例えば上で述べた離散フーリエ変換は \[ \underbrace{\begin{pmatrix} \widehat{u}_0 \cr \widehat{u}_1 \cr \vdots \cr \widehat{u}_{M-1} \end{pmatrix}}_{=\widehat{\mathbf{u}}} = \underbrace{\dfrac{1}{M}\begin{pmatrix} \omega^0 & \omega^0 & \dots & \omega^0 \cr \omega^0 & \omega^1 & \dots & \omega^{M-1} \cr \vdots & \vdots & \ddots & \vdots \cr \omega^0 & \omega^{M-1} & \dots & \omega^{(M-1)^2} \end{pmatrix}}_{=F}\underbrace{\begin{pmatrix} u_0 \cr u_1 \cr \vdots \cr u_{M-1} \end{pmatrix}}_{=\mathbf{u}} \] と表記することができる. ここで行列 $F$ を 離散フーリエ変換行列 と呼ぶことにする. 同様に, 離散フーリエ逆変換は \[ \mathbf{u} = \begin{pmatrix} \omega^0 & \omega^0 & \dots & \omega^0 \cr \omega^0 & \omega^{-1} & \dots & \omega^{-(M-1)} \cr \vdots & \vdots & \ddots & \vdots \cr \omega^0 & \omega^{-(M-1)} & \dots & \omega^{-(M-1)^2} \end{pmatrix}\widehat{\mathbf{u}} \] と表すことができる. ところで, $M$ が偶数であることから \[ \omega^m = e^{-2\pi i m/M} = -e^{-\pi i -2\pi i m/M} = -\omega^{m+M/2} \] であり, 従って \[ \sum_{k=0}^{M-1}\omega^k = \underbrace{\omega^0 + \omega^{M/2}}_{=0} + \underbrace{\omega^1 + \omega^{1+M/2}}_{=0} + \dots + \underbrace{\omega^{M/2-1} + \omega^{M-1}}_{=0} = 0 \] である. これを用いると, 上に述べた離散フーリエ逆変換に現れる行列は $F^{-1}$ であることが確かめられる. 従って, 離散フーリエ変換と離散フーリエ逆変換はそれぞれ \[ \widehat{\mathbf{u}} = F\mathbf{u},\qquad \mathbf{u} = F^{-1}\widehat{\mathbf{u}}. \] と表すことができる. フーリエ変換を利用すると, 微分や畳み込み積の計算が簡単な式に変換できるという利点があるが, 離散フーリエ変換にも同様の利点があり, 数値計算にも応用される.

ただし上のような式変形は, 離散的な周期境界条件 $u_0 = u_M$ に依存している. 一方で, 例えば斉次ディリクレ境界条件 $u_0 = u_M = 0$ 下では, \[ u_{-m} = -u_m \] と定めることで (直感的には奇関数として対象に拡張することで) 周期境界条件を作り, これに対する離散フーリエ変換を考えるとサイン関数だけが残る. このようなアイデアに基づき導出される 離散サイン変換行列 \[ S = \dfrac{2}{M}\begin{pmatrix} \sin (1/M\pi) & \sin (2/M\pi) & \dots & \sin ((M-1)/M\pi) \cr \sin (2/M\pi) & \sin (2^2/M\pi) & \dots & \sin (2(M-1)/M\pi) \cr \vdots & \vdots & \ddots & \vdots \cr \sin ((M-1)/M\pi) & \sin (2(M-1)/M\pi) & \dots & \sin ((M-1)^2/M\pi) \end{pmatrix} \] およびその逆行列 \[ S^{-1} = \begin{pmatrix} \sin (-1/M\pi) & \sin (-2/M\pi) & \dots & \sin (-(M-1)/M\pi) \cr \sin (-2/M\pi) & \sin (-2^2/M\pi) & \dots & \sin (-2(M-1)/M\pi) \cr \vdots & \vdots & \ddots & \vdots \cr \sin (-(M-1)/M\pi) & \sin (-2(M-1)/M\pi) & \dots & \sin (-(M-1)^2/M\pi) \end{pmatrix} = \dfrac{M}{2}S \] を用いると, 斉次ディリクレ境界条件に対応する 離散サイン変換 および 離散サイン逆変換 が得られる (この $M$ はもはや偶数でなくとも構わない). これの典型的な応用例として, 斉次ディリクレ境界条件下での離散ラプラシアン \[ L_h = \dfrac{1}{h^2}\begin{pmatrix} -2 & 1 & 0 & \dots & 0 \cr 1 & -2 & 1 & \dots & 0 \cr 0 & 1 & -2 & \dots & 0 \cr \vdots & \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & 0 &\dots & -2 \end{pmatrix} \in \mathbb{R}^{(M-1)\times (M-1)} \] について考えてみよう. この行列の固有値および対応する固有ベクトルは \[ \lambda_j = -\dfrac{4}{h^2}\sin^2\dfrac{j\pi}{2M},\qquad \mathbf{v}_j = \begin{pmatrix} \sin \dfrac{j\pi x_1}{L} \cr \vdots \cr \sin \dfrac{j\pi x_{M-1}}{L} \end{pmatrix} \in\mathbb{R}^{M-1}\qquad (j=1, 2, \dots, M-1) \] であったことを思い出しておこう. いま, $j\pi x_m/L = \pi jm/M$ であることに注意すると, 離散ラプラシアンの対角化は \[ L_h = S^{-1}\begin{pmatrix} \lambda_1 & 0 & \dots & 0 \cr 0 & \lambda_2 & \dots & 0 \cr \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & \dots & \lambda_{M-1} \end{pmatrix} S \] となることがわかる. つまり, 与えられたベクトル $\mathbf{v}\in\mathbb{R}^{M-1}$ に対して $L_h\mathbf{v}$ を計算する, という操作は,

  1. $S\mathbf{v}$ を計算する, つまり離散サイン変換を行う,
  2. 離散サイン変換の結果に対角行列を掛ける,
  3. その結果に$S^{-1}$ を左から掛ける, つまり離散サイン逆変換を行う

という形に書き直すことができる. このように, 離散フーリエ変換や離散サイン変換などは差分法の計算とも密接に関連している. さらにこのような変形は, コンピュータにより効率的に行列ベクトル積を計算する (高速フーリエ変換 に相当する) テクニックの基盤となる, 重要なアイデアである.

準備が長くなったが, ここからスペクトル法について解説しよう. 具体例として, フィッシャー = KPP 方程式 \[ u_t = ku_{xx} + ru(1-u) \quad \text{in}\quad \mathbb{R} \] に対する数値計算を, スペクトル法により実行することを考える. ただし, 数値計算の都合上, 無限区間を厳密に扱うことができないため, ここでは代わりに \[ \left\{\begin{array}{l} u_t = ku_{xx} + ru(1-u) \quad \text{in}\quad [0, L], \cr u(0, t) = 1,\quad u(L, t) = 0 \end{array}\right. \] を考えることにする (初期条件は適当に与えることにする).

まず, 記号の簡単のために $f(u) = u(1-u)$ とおく. 次に, 方程式を斉次ディリクレ境界条件に帰着させるために, 例えば $g(x) = 1-x/L$ を用いて \[ v(x, t) = u(x, t) - g(x) \] とおく. この $v$ は ($g_t = g_{xx} = 0$ であることに注意すると) \[ v_t = k\Delta_D v + rf(v+g) \quad \text{in}\quad [0, L] \] を満たすので, この解となる $v(x, t)$ の近似を計算し, それに関数 $g(x)$ を加えたものを $u(x, t) = v(x, t) + g(x)$ の近似とすれば良い.

スペクトル法では, 微分方程式の解を多項式や三角関数の和で近似する. ここでは斉次ディリクレ境界条件を考慮し, 微分作用素の固有関数であるサイン関数たちの足し合わせにより近似しよう: 区間 $[0, L]$ を $M$ 等分し, $h=L/M$, $x_m = mh$ とおく. このとき, \[ \varphi_j(x) = \sin \dfrac{j\pi x}{L} \] とおき, \[ v_h(x, t) = \sum_{j=1}^{M-1}\widehat{v}_j(t)\varphi_j(x) \] と定める. これが $v(x, t)$ の近似となるように $\widehat{v}_j(t)$ を定めたい. そのために, ここでは残差に対し重み $\varphi_j$ を掛けた重み付き積分が $0$ となること, つまり \[ \int_0^L (v_h)_t\varphi_i~dx = \int_0^L (k\Delta_D v_h+rf(v_h+g))\varphi_i~dx \quad \text{for all}\quad i=1, 2, \dots, M-1 \] となることを要請してみよう (このような近似解の構成は 重み付き残差法 と総称される). 三角関数の直交性に注意すると \[ \int_0^L \varphi_i(x)\varphi_j(x) ~dx = \dfrac{L}{2}\delta_{ij} \] となることから, 上の式は \[ (\widehat{v}_i)_t = -k\left(\dfrac{i\pi}{L}\right)^2\widehat{v}_i + \dfrac{2}{L}\int_0^Lrf(v_h+g)\varphi_i \quad\text{for all}\quad i = 1,\dots, M-1 \] と変形できる. これを解いて $\widehat{v}_i(t)$ が得られれば, そこから $v_h(x, t)$ を構成することができる. これがスペクトル法による空間半離散化のアイデアである.

ただし, 実際の数値計算の際には, 関数 $v_h(x, t)$ ではなく, 各点 $x_m$ 上での値 $v_h(x_m, t)$ のみ求めることが多い. いま, $v_h(x_m, t)$ を第 $m$ 成分に持つベクトルを $\mathbf{v}$ とおくと, \[ \mathbf{v} = \begin{pmatrix} v_1 \cr \vdots \cr v_{M-1} \end{pmatrix} = \begin{pmatrix} \displaystyle\sum_{j=1}^{M-1} \widehat{v}_j\varphi_j(x_1) \cr \vdots \cr \displaystyle\sum_{j=1}^{M-1} \widehat{v}_j\varphi_j(x_{M-1}) \end{pmatrix} = \underbrace{\begin{pmatrix} \varphi_1(x_1) & \varphi_2(x_1) & \dots & \varphi_{M-1}(x_1) \cr \varphi_1(x_2) & \varphi_2(x_2) & \dots & \varphi_{M-1}(x_2) \cr \vdots & \vdots & \ddots & \vdots \cr \varphi_1(x_{M-1}) & \varphi_2(x_{M-1}) & \dots & \varphi_{M-1}(x_{M-1}) \end{pmatrix}}_{=S^{-1}} \underbrace{\begin{pmatrix} \widehat{v}_1 \cr \vdots \cr \widehat{v}_{M-1} \end{pmatrix}}_{=\widehat{\mathbf{v}}} \] と表すことができ, ここに離散サイン行列の逆が現れる.

また, 以下では非線形項 $f$ についての積分を計算する代わりに, $f(v_h(x_m, t)+g(x_m))$ を第 $m$ 成分に持つベクトル $\mathbf{f}$ に対し \[ \widehat{\mathbf f} = S\mathbf{f} \] を計算し, これを近似として用いることにする (このようなアイデアは 擬スペクトル法 と呼ばれることがある). つまり, \[ v_t = k\Delta_D v + rf(v+g) \] に対する (擬) スペクトル法に基づく空間半離散化では, \[ \widehat{\mathbf{v}}_t = k\underbrace{\begin{pmatrix} -(\pi/L)^2 & 0 & \dots & 0 \cr 0 & -(2\pi/L)^2 & \dots & 0 \cr \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & \dots & -((M-1)\pi/L)^2 \end{pmatrix}}_{=A_h}\widehat{\mathbf{v}} + r\widehat{\mathbf{f}} \] を導出し, これを解いて $\widehat{v}_i(t)$ を求め, ここから $v(x, t)$ の近似を表す $\mathbf{v}(t)$ を構成することになる. 離散サイン変換行列 $S$ を用いれば, 直接 \[ \mathbf{v}_t = kS^{-1}A_hS\mathbf{v} + r\mathbf{f} \] と表すこともできるが, $S^{-1}A_hS$ の部分が, $\Delta_D$ に対するスペクトル法における近似を表す行列となっている. つまり, $\Delta_D v$ に対する近似計算として, スペクトル法では

  1. $\mathbf{v}$ を離散サイン変換して $\widehat{\mathbf{v}} = S\mathbf{v}$ を得る,
  2. $\widehat{\mathbf{v}}$ に第 $(i, i)$ 成分が $-(i\pi/L)^2$ である対角行列 $A_h$ を掛ける,
  3. $A_h\widehat{\mathbf{v}}$ を離散サイン逆変換して $\Delta_D v$ の近似となるベクトル $S^{-1}A_hS\mathbf{v}$ が得られる
ということを意味しており, 微分作用素の固有関数の線型結合で近似解を構成することで, 微分を各モードに対する単純な積に置き換えることができている. この変形は, 通常のフーリエ変換を利用すると, 与えられた関数 $v(x)$ の二階微分を

  1. フーリエ変換する,
  2. $(\sqrt{-1}\omega)^2$ を掛ける,
  3. フーリエ逆変換する

という手順で計算できることに相当するものである.

あとは時間離散化も用いて数値計算をすれば良いが, このときも非線形項の扱いが面倒なので, ここでは 半陰的オイラー法 (semi-implicit Euler) \[ \dfrac{\mathbf{v}^{n+1} - \mathbf{v}^n}{\tau} = k S^{-1}A_hS\mathbf{v}^{n+1} + r\mathbf{f}^n \] を採用することにする. これを整理すると \[ \widehat{\mathbf{v}}^{n+1} = (I-\tau kA_h)^{-1}(\widehat{\mathbf{v}}^n + \tau r\widehat{\mathbf{f}}^n) \] となるが, 行列 $(I-\tau kA)^{-1}$ は第 $(m, m)$ 成分が \[ \dfrac{1}{1+\tau k(m\pi/L)^2} \] である対角行列であり, 従って半陰的オイラー法の計算は \[ \widehat{v}^{n+1}_m = \dfrac{\widehat{v}^n_m + \tau r \widehat{f}^n_m}{1+\tau k(m\pi/L)^2}\quad \text{for all}\quad m=1, \dots, M-1 \] と表すことができ, 容易に計算可能である.

実際の数値計算の手順としては

  1. 第 $m$ 成分が $v_m^n \approx v(x_m, t_n)$ であるベクトル $\mathbf{v}^n$ から, 第 $m$ 成分が $f(u_m^n) = f(v_m^n+g(x_m))$ であるベクトル $\mathbf{f}^n$ を求める.
  2. 離散サイン変換により \[ \widehat{\mathbf{v}}^n = S\mathbf{v}^n,\quad \widehat{\mathbf{f}}^n = S\mathbf{f}^n \] をそれぞれ計算する.
  3. 半陰的オイラー法に基づき, \[ \widehat{\mathbf{v}}^{n+1} = (I-\tau kA)^{-1}(\widehat{\mathbf{v}}^n + \tau r\widehat{\mathbf{f}}^n) \] と定める.
  4. 離散サイン逆変換により \[ \mathbf{v}^{n+1} = S^{-1}\widehat{\mathbf{v}}^{n+1} = \dfrac{M}{2}S\widehat{\mathbf{v}}^{n+1} \] を計算する.

とすれば良い. ベクトル $\mathbf{v}^{n+1}$ の各成分が $v(x_m, t_{n+1})$ の近似を表すため, $u(x_m, t_{n+1}) = v(x_m, t_{n+1}) + g(x_m)$ の近似 $u_m^{n+1} = v_m^{n+1} + g(x_m)$ が得られる.

なお, このページ下部にあるサンプルコードでは, 分かりやすさのために離散サイン変換行列を直接構成して行列ベクトル積を計算しているが, 本来は高速フーリエ変換に相当するテクニックを利用して効率的に計算すべきだろう. Python では比較的容易に利用できるため, 興味があれば調べてみると良い.

A.5: 離散変分導関数法

4.3: 勾配系とハミルトン系 において, 構造保存型数値解法の一例としてハミルトン系に対する離散勾配法を紹介した. ここでは時間発展 PDE に対する構造保存型数値解法の一種として, 離散変分導関数法 (discrete variational derivative method) を紹介しよう. 例として カーン=ヒリアード方程式 (Cahn-Hilliard equation) \[ u_t = -(\varepsilon^2 u_{xx} + \gamma u(1-u^2))_{xx} \] を考える, ここで $\varepsilon\gt 0$ と $\gamma\gt 0$ はパラメータである. いま, \[ \mu = -(\varepsilon^2 u_{xx} + \gamma u(1-u^2)) \] とおくと, 上の式は \[ u_t = \mu_{xx} \] と表すこともできる (この $\mu$ は化学ポテンシャルと呼ばれることがある). ここでは境界条件 (および初期条件) として, \[ \left\{\begin{array}{l} u_t = -(\varepsilon^2 u_{xx} + \gamma u(1-u^2))_{xx} \quad \text{in}\quad [0, L], \cr u_x(0, t) = u_x(L, t) = 0, \cr \mu_{x}(0, t) = \mu_{x}(L, t) = 0, \cr u(x, 0) = u_0(x) \end{array}\right. \] を考えることにする. 特に, 境界における空間 $1$ 階微分 (より正確には法線微分) の値を指定する境界条件は ノイマン境界条件 と呼ばれる. 今回は $1$ 階微分の境界値が $0$ であるという条件を課しているが, これは 斉次ノイマン境界条件 と呼ばれる.

ところで, カーン=ヒリアード方程式は上のような適切な境界条件の下で質量保存則を満たす. 実際, \[ \begin{array}{rl} \dfrac{d}{dt}\displaystyle\int_0^L u~dx &= \displaystyle\int_0^L u_t ~dx \cr &= \displaystyle\int_0^L \mu_{xx} ~dx \cr &= \left[\mu_x\right]_0^L = 0 \end{array} \] であるため, $u$ を区間 $[0, L]$ 上で積分した値は時間 $t$ には依存しない, つまり質量が時間経過により変化しないことがわかる. さらに, この問題については, \[ E(u) = \dfrac{u^4}{4} - \dfrac{u^2}{2},\qquad G(u, u_x) = \dfrac{\varepsilon^2}{2}u_x^2 +\gamma E(u),\qquad J(u) = \int_0^L G(u, u_x)~dx \] により定められる $J(u)$ が, 時間とともに減少するということも知られている. ここで $E(u)$ は (グラフの形状から) 二重井戸型ポテンシャル と呼ばれ, また $G(u, u_x)$, $J(u)$ はそれぞれカーン=ヒリアード方程式の 局所エネルギー, 全エネルギー と呼ばれることがある. このことを確認するために, $G(u, u_x)$ に対する 変分導関数 \[ \dfrac{\delta G}{\delta u} = \dfrac{\partial G}{\partial u} - \dfrac{\partial}{\partial x}\dfrac{\partial G}{\partial u_x} \] を導入しよう. なお, この変分導関数は, $J$ の変分を計算する際に \[ \left.\dfrac{d}{d\varepsilon}\right|_{\varepsilon=0}J(u+\varepsilon v) = \int_0^L\left(\dfrac{\partial G}{\partial u}v + \dfrac{\partial G}{\partial u_x}v_x\right)~dx = \int_0^L\dfrac{\delta G}{\delta u}v~dx \quad \text{for all}\quad v\in C^{\infty}_0(0, L) \] を満たすものである. 上の $G(u, u_x)$ の変分導関数を実際に計算すると, \[ \dfrac{\delta G}{\delta u} = -\gamma u + \gamma u^3 - \dfrac{\partial}{\partial x}\varepsilon^2 u_x = -(\varepsilon^2 u_{xx} + \gamma u (1-u^2)) = \mu \] が得られる. つまりカーン=ヒリアード方程式は \[ u_t = \left(\dfrac{\delta G}{\delta u}\right)_{xx} \] であると思うことができ, また境界条件から \[ \left\{\begin{array}{rll} \dfrac{\partial G}{\partial u_x} &= \varepsilon^2 u_x = 0 & (x=0, L), \cr \left(\dfrac{\delta G}{\delta u}\right)_x &= \mu_x = 0 & (x=0, L) \end{array}\right. \] が得られることも用いると, 実際に \[ \begin{array}{rl} \dfrac{d}{dt}J(u) &= \displaystyle\int_0^L \dfrac{\partial G(u, u_x)}{\partial t}~dx \cr &= \displaystyle\int_0^L\left(\dfrac{\partial G}{\partial u}u_t + \dfrac{\partial G}{\partial u_x}u_{xt}\right)~dx \cr &= \displaystyle\int_0^L \dfrac{\partial G}{\partial u}u_t ~ dx + \underbrace{\left[\dfrac{\partial G}{\partial u_x}u_t\right]_0^L}_{=0} -\int_0^L \dfrac{\partial}{\partial x}\dfrac{\partial G}{\partial u_x}u_{t}~dx \cr &= \displaystyle\int_0^L \dfrac{\delta G}{\delta u}u_t ~ dx \cr &= \displaystyle\int_0^L \dfrac{\delta G}{\delta u}\left(\dfrac{\delta G}{\delta u}\right)_{xx} ~ dx \cr &= \underbrace{\left[\dfrac{\delta G}{\delta u}\left(\dfrac{\delta G}{\delta u}\right)_{x}\right]_0^L}_{=0} - \displaystyle\int_0^L \left(\dfrac{\delta G}{\delta u}\right)_{x}^2 ~ dx \le 0 \end{array} \] のように式変形することで, $J(u)$ は時間 $t$ について単調減少であることが確かめられる (もちろん変分導関数を用いずに式変形することで同じ結論を得ることもできる).

さて, 単純な $4$ 階差分に基づく計算やスペクトル法などでも (時間刻み幅 $\tau$ などに対する十分に良い仮定の下で) カーン=ヒリアード方程式の数値計算は可能であるが, 汎用解法による数値計算結果が上のような厳密解の性質を再現するとは限らない. そこで, 上で述べた性質を再現するように構成された構造保存型数値解法を考えたい. そのために, カーン=ヒリアード方程式そのものではなく, 変分導関数を用いて表される等式や不等式に対する近似を構成しよう. このようなアイデアに基づく数値計算手法を 離散変分導関数法 という.

カーン=ヒリアード方程式に対する離散変分導関数法のアイデアについて具体的に説明しよう. 本来, 離散変分導関数法において空間離散化と時間離散化は同時に説明されることが多いが, ここでは空間半離散化により常微分方程式系を導出し, その後で後退オイラー法を適用する, という順序で解説してみる.

まず, 空間半離散化については差分法を用いる. 区間 $[0, L]$ を $M$ 等分することで空間分割幅を $h = L/M\gt0$ とし, $x_m = mh$ とする. このとき, カーン=ヒリアード方程式の解 $u$ に対し, $u(x_m, t)$ の近似を与える $u_m$ ($m=0, 1, \dots, M$) を求めたい. 以降, $u_m$ を第 $m+1$ 成分としてもつベクトルを $\mathbf{u}(t)\in\mathbb{R}^{M+1}$ と表記する: \[ \mathbf{u} = \begin{pmatrix} u_0 \cr u_1 \cr \vdots \cr u_M \end{pmatrix} \in \mathbb{R}^{M+1}. \] 境界条件の違いから, アレン=カーン方程式などこれまでのベクトルの表記とは異なっていることに注意. 以降現れる $M+1$ 次行ベクトルの各成分も同様に表記する. 斉次ノイマン境界条件 \[ u_x(0) = u_x(L) = 0 \] を差分法において近似的に表現する方法はいくつかあるが, ここでは $x_{-1}$ および $x_{M+1}$ に対応する "仮想的" な値 $u_{-1}$, $u_{M+1}$ を \[ \dfrac{u_1 - u_{-1}}{2h} = \dfrac{u_{M+1} - u_{M-1}}{2h} = 0 \] が満たされるように定めることにする. 境界条件の扱いを容易にするために値が設定される仮想的な点を 仮想格子点 (ghost point) と呼ぶことがあるが, 上は仮想格子点上での $u_m$ の値を \[ u_{-1} = u_1,\quad u_{M+1} = u_{M-1} \] と設定していることを意味している. 以降現れる全ての $M+1$ 次行ベクトルに対しても, 同様に仮想格子点上での値を設定することにする.

これに注意すると, 中心二階差分により例えば \[ u_{xx}(x_0) \approx \dfrac{u_{-1} - 2u_0 + u_1}{h^2} = \dfrac{-2u_0 + 2u_1}{h^2} \] のように近似することができるため, これに基づくノイマン境界条件下での離散ラプラシアンは \[ L_h = \dfrac{1}{h^2}\begin{pmatrix} -2 & 2 & 0 & 0 & \dots & 0 \cr 1 & -2 & 1 & 0 & \dots & 0 \cr 0 & 1 & -2 & 1 & \dots & 0 \cr \vdots & \vdots & \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & 0 & 0 & \dots & -2 \end{pmatrix}\in\mathbb{R}^{(M+1)\times (M+1)} \] となる. また, 離散 $L^2$ 内積については, 通常の $L^2$ 内積に対する台形則による近似に基づき \[ (\mathbf{v}, \mathbf{w})_h = \left(\dfrac{1}{2}v_0w_0 + \sum_{m=1}^{M-1}v_mw_m + \dfrac{1}{2}v_Mw_M\right)h \] と定める. やはり境界条件の違いから, 以前の定義とは異なっていることに注意. さらに, \[ S(\mathbf{v}) = \left(\dfrac{1}{2}v_0 + \sum_{m=1}^{M-1}v_m + \dfrac{1}{2}v_M\right)h \] と定める (これは関数 $v_h(x)$ の積分に対する台形則による近似に相当している).

このとき, ノイマン境界条件下で離散ラプラシアン $L_h\in\mathbb{R}^{(M+1)\times (M+1)}$ は, 任意のベクトル $\mathbf{v}, \mathbf{w}\in\mathbb{R}^{M+1}$ に対して, \[ S(L_h\mathbf{v}) = 0,\qquad (L_h\mathbf{v}, \mathbf{w})_h = -(G_h\mathbf{v}, G_h\mathbf{w})_e = (\mathbf{v}, L_h\mathbf{w})_h,\qquad (\mathbf{v}, L_h\mathbf{v})_h \le 0 \] を満たす, ここで \[ G_h = \dfrac{1}{h}\begin{pmatrix} -1 & 1 & 0 & \dots & 0 & 0 \cr 0 & -1 & 1 & \dots & 0 & 0 \cr \vdots & \vdots & \ddots & \ddots & \vdots & \vdots \cr 0 & 0 & 0 & \dots & -1 & 1 \end{pmatrix} \in \mathbb{R}^{M\times(M+1)} \] は斉次ノイマン境界条件に対する離散勾配であり, また第 $m$ 成分が $p_m$, $q_m$ であるベクトル $\mathbf{p}$, $\mathbf{q}\in\mathbb{R}^M$ に対して \[ (\mathbf{p}, \mathbf{q})_e = \sum_{m=1}^Mp_mq_mh \] である. 上の式は斉次ノイマン境界条件より \[ \int_0^Lv_{xx}~dx = \left[v_x\right]_0^L = 0,\qquad \int_0^L v_{xx}w~dx = -\int_0^L v_xw_x~dx = \int_0^Lvw_{xx}~dx,\qquad \int_0^Lvv_{xx}~dx = -\int_0^L|v_x|^2~dx \le 0 \] が成立することを再現していると解釈でき, 具体的な式の形は異なるものの斉次ディリクレ境界条件の場合と同様のアイデアによるものである.

これらを実際に確かめてみよう. 説明のために, \[ H = \begin{pmatrix} 1/2 & 0 & \dots & 0 \cr 0 & 1 & \dots & 0 \cr \vdots & \vdots & \ddots & \vdots \cr 0 & 0 & \dots & 1/2 \end{pmatrix} \in\mathbb{R}^{(M+1)\times (M+1)} \] という対角行列を用意すると, \[ (\mathbf{v}, \mathbf{w})_h = h\mathbf{v}^{\operatorname{T}}H\mathbf{w} \] となり, また \[ -HL_h = G_h^{\operatorname{T}}G_h \] が成立し, 特にこれは対称行列である (斉次ディリクレ境界条件の場合と比較すると, 行列 $H$ が挿入されることのみ異なっている). ここで, $H$ も対称行列であることに注意すると \[ \begin{array}{rl} (L_h\mathbf{v}, \mathbf{w})_h &= h(L_h\mathbf{v})^{\operatorname{T}}H\mathbf{w} \cr &= h\mathbf{v}^{\operatorname{T}}HL_h\mathbf{w} \cr &= -(G_h\mathbf{v}, G_h\mathbf{w})_e \cr &= (\mathbf{v}, L_h\mathbf{w})_h \end{array} \] が得られる. また, これを用いると, 全ての成分が $1$ であるベクトル $\mathbf{1}$ に対して \[ S(L_h\mathbf{v}) = (L_h\mathbf{v}, \mathbf{1})_h = -(G_h\mathbf{v}, \underbrace{G_h\mathbf{1}}_{=\mathbf{0}})_e = 0 \] と式変形でき, さらに \[ (\mathbf{v}, L_h\mathbf{v}) = -\|G_h\mathbf{v}\|_e^2 \le 0 \] も確かに得られる.

これらの記号を用いると, 斉次ノイマン境界条件下でのカーン=ヒリアード方程式に対する離散変分導関数法による空間半離散化は, 大雑把には以下のように説明できる:

  1. 全エネルギー $J(u)$ の近似を表す $J_h(\mathbf{u})$ を構成する. ここでは, \[ J(u) = \int_0^L G(u, u_x)~dx = \int_0^L \dfrac{\varepsilon^2}{2}u_x^2 + \gamma E(u)~dx \] の近似 $J_h(\mathbf{u}^n)$ を, 積分に対する台形則により定めよう: ベクトル $\mathbf{G}(\mathbf{u})$ を適切に定めることで, \[ J_h(\mathbf{u}) = S(\mathbf{G}(\mathbf{u})) = \dfrac{\varepsilon^2}{2}\|G_h\mathbf{u}\|_e^2 + \gamma S(\mathbf{E}(\mathbf{u})) \] とする, ここで $\mathbf{E}(\mathbf{u})$ は, 第 $m+1$ 成分が $E(u_m)$ であるベクトルである.
  2. 変分導関数を用いて表される連鎖律 \[ \dfrac{d}{dt}J(u) = \int_0^L\dfrac{\delta G}{\delta u}u_t~dx \le 0 \] を (積分については先ほどと同じく台形則を用いて) \[ S\left(\dfrac{d}{dt}\mathbf{G}(\mathbf{u})\right) = \dfrac{d}{dt}J_h(\mathbf{u}) = \left(\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}, \mathbf{u}_t\right)_h \] という離散的な "連鎖律" で近似することで, これを満たす \[ \dfrac{\delta \mathbf{G}}{\delta\mathbf{u}} = -(\varepsilon^2 L_h\mathbf{u} + \gamma \mathbf{W}(\mathbf{u})) \] が得られる, ただし $\mathbf{W}(\mathbf{u})$ は第 $m+1$ 成分が $u_m(1-(u_m)^2)$ であるベクトルである.
  3. 変分導関数を用いて表されるカーン=ヒリアード方程式 \[ u_t = \left(\dfrac{\delta G}{\delta u}\right)_{xx} = -(\varepsilon^2 u_{xx} + \gamma u(1-u^2))_{xx} \] の近似として, \[ \mathbf{u}_t = L_h\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}} = -L_h(\varepsilon^2 L_h\mathbf{u} + \gamma \mathbf{W}(\mathbf{u})) \] を得る.

このとき, 確かに \[ \dfrac{d}{dt}S(\mathbf{u}) = S(\mathbf{u}_t) = S\left(L_h\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}\right) = 0 \] および \[ \dfrac{d}{dt}J_h(\mathbf{u}) = \left(\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}, \mathbf{u}_t\right)_h = \left(\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}, L_h\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}\right)_h \le 0 \] が成立するため, この空間半離散化はカーン=ヒリアード方程式の性質を再現していることがわかる.

それでは, 次に時間離散化についても考えてみよう. 上の空間半離散化を整理すると, \[ \dfrac{d}{dt}J_h(\mathbf{u}) = S\left(\dfrac{d}{dt}\mathbf{G}(\mathbf{u})\right) = \left(\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}, \mathbf{u}_t\right)_h \] を満たす $\delta \mathbf{G}/\delta\mathbf{u}\in\mathbb{R}^{M+1}$ に対し \[ \mathbf{u}_t = L_h \dfrac{\delta\mathbf{G}}{\delta\mathbf{u}} \] という常微分方程式系を考える, ということになる. ここでは, 時間微分を後退オイラー法により近似し, これに整合する離散的な変分導関数を構成する: 時間刻み幅を $\tau \gt0$ とし, $t_n = n\tau$ とする. このとき, $\mathbf{u}(t_n)$ の近似を与える $\mathbf{u}^n$ を, \[ \dfrac{J_h(\mathbf{u}^{n+1}) - J_h(\mathbf{u}^n)}{\tau} = S\left(\dfrac{\mathbf{G}(\mathbf{u}^{n+1}) - \mathbf{G}(\mathbf{u}^n)}{\tau}\right) = \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, \dfrac{\mathbf{u}^{n+1}-\mathbf{u}^n}{\tau}\right)_h \] を満たす 離散変分導関数 $\delta \mathbf{G}/\delta(\mathbf{u}^{n+1}, \mathbf{u}^n)\in\mathbb{R}^{M+1}$ に対し \[ \dfrac{\mathbf{u}^{n+1}-\mathbf{u}^n}{\tau} = L_h \dfrac{\delta\mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^n)} \] を解くことで決定しよう. なお, 今回のエネルギー $J$ に対する離散変分導関数は \[ J_h(\mathbf{u}^{n+1}) - J_h(\mathbf{u}^n) = \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, \mathbf{u}^{n+1}-\mathbf{u}^n\right)_h \] を満たすものであり, 従って $J_h$ の (離散 $L^2$ 内積に対する勾配 $\nabla_h J_h$ を近似する) 離散勾配 $\overline{\nabla}_hJ_h$ に相当するものとなっている.

離散変分導関数を具体的にどのように構成するか, という問題はあるが, その前に上の式から得られる $\mathbf{u}^{n+1}$ の性質を確認しておくと, \[ \begin{array}{rl} \dfrac{S(\mathbf{u}^{n+1}) - S(\mathbf{u}^n)}{\tau} &= S\left(\dfrac{\mathbf{u}^{n+1}-\mathbf{u}^n}{\tau}\right) \cr &= S\left(L_h\dfrac{\delta\mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^n)}\right) \cr &= 0, \end{array} \] および \[ \begin{array}{rl} \dfrac{J_h(\mathbf{u}^{n+1}) - J_h(\mathbf{u}^n)}{\tau} &= \dfrac{S(\mathbf{G}(\mathbf{u}^{n+1})) - S(\mathbf{G}(\mathbf{u}^n))}{\tau} \cr &= S\left(\dfrac{\mathbf{G}(\mathbf{u}^{n+1}) - \mathbf{G}(\mathbf{u}^n)}{\tau}\right) \cr &= \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, \dfrac{\mathbf{u}^{n+1}-\mathbf{u}^n}{\tau}\right)_h \cr &= \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, L_h\dfrac{\delta\mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^n)}\right)_h \cr & \le 0 \end{array} \] が満たされていることがわかる. つまり, この数値計算により得られる $\mathbf{u}^n$ は, 時間経過による質量保存とエネルギー減衰という構造を再現することが数学的に保証される. このことが, 離散変分導関数法の大きな利点である.

それでは, 離散変分導関数 \[ \dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^n, \mathbf{u}^{n+1})} \] の具体的な構成を試みよう. 以降, さらなる記号の簡単のために \[ D_{\tau}u_m^n = \dfrac{u^{n+1}_m - u^n_m}{\tau},\quad D_{\tau}\mathbf{u}^n = \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau}, \quad u^{n+1/2}_m = \dfrac{u^{n+1}_m + u^n_m}{2}, \quad \mathbf{u}^{n+1/2} = \dfrac{\mathbf{u}^{n+1} + \mathbf{u}^n}{2} \] という表記を導入しよう. まず, 準備としてベクトル $\mathbf{E}(\mathbf{u})$ の第 $m+1$ 成分は \[ E(u_m) = \dfrac{(u_m)^4}{4} - \dfrac{(u_m)^2}{2} \] であったことを思い出しておく. ここで, 第 $m+1$ 成分が \[ \begin{array}{rl} W_m &= -\dfrac{E(u_m^{n+1}) - E(u_m^n)}{u_m^{n+1}-u_m^n} \cr &= -\left(\dfrac{1}{4}((u_m^{n+1})^2 + (u_m^n)^2)(u_m^{n+1} + u_m^n) - \dfrac{u_m^{n+1}+u_m^n}{2}\right) \cr &= u^{n+1/2}_m\left(1- \dfrac{(u^{n+1}_m)^2 + (u^n_m)^2}{2}\right) \end{array} \] であるベクトルを $\mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n)$ とおくと, \[ \begin{array}{rl} \dfrac{1}{\tau}S(\mathbf{E}(\mathbf{u}^{n+1}) - \mathbf{E}(\mathbf{u}^n)) &= \dfrac{1}{\tau}(\mathbf{E}(\mathbf{u}^{n+1}) - \mathbf{E}(\mathbf{u}^n), \mathbf{1})_h \cr &= \dfrac{1}{\tau}(-\mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n), \mathbf{u}^{n+1} - \mathbf{u}^n)_h \cr &= -(\mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n), D_{\tau}\mathbf{u}^n)_h \end{array} \] が得られる. これを用いて, 離散変分導関数を定義する式を変形することで, \[ \begin{array}{rl} \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, D_{\tau}\mathbf{u}^n\right)_h &= S\left(\dfrac{\mathbf{G}(\mathbf{u}^{n+1}) - \mathbf{G}(\mathbf{u}^n)}{\tau}\right) \cr &= \dfrac{\varepsilon^2}{2\tau}\left(\|G_h\mathbf{u}^{n+1}\|_e^2 - \|G_h\mathbf{u}^n\|_e^2 + \gamma (S(\mathbf{E}(\mathbf{u}^{n+1}) - \mathbf{E}(\mathbf{u}^n)))\right) \cr &= \dfrac{\varepsilon^2}{2\tau}(G_h\mathbf{u}^{n+1} + G_h\mathbf{u}^n, G_h\mathbf{u}^{n+1} - G_h\mathbf{u}^n)_e - \gamma (\mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n), D_{\tau}\mathbf{u}^n)_h \cr &= -\varepsilon^2(L_h\mathbf{u}^{n+1/2}, D_{\tau}\mathbf{u}^n)_h - \gamma (\mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n), D_{\tau}\mathbf{u}^n)_h \cr &= \left(-(\varepsilon^2L_h\mathbf{u}^{n+1/2} + \gamma \mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n)), D_{\tau}\mathbf{u}^n\right)_h \end{array} \] が得られるため, 離散変分導関数は \[ \dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})} = -(\varepsilon^2L_h\mathbf{u}^{n+1/2} + \gamma \mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n)) \] と定めれば良いことがわかった. 以上より, カーン=ヒリアード方程式 \[ \left\{\begin{array}{l} u_t = -\Delta(\varepsilon^2 \Delta u + \gamma u(1-u^2)) \quad \text{in}\quad [0, L], \cr u_x(0, t) = u_x(L, t) = 0, \cr u_{xxx}(0, t) = u_{xxx}(L, t) = 0 \end{array}\right. \] に対する離散変分導関数法による数値計算スキームは \[ \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau} = -L_h\left(\varepsilon^2L_h\mathbf{u}^{n+1/2} + \gamma \mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n)\right) \] である.

以上の議論による離散化の対応を簡単にまとめておこう:

  • カーン=ヒリアード方程式: \[ \begin{array}{c} u_t = -\Delta_N(\varepsilon^2 \Delta_N u + \gamma W(u)), \quad\text{where} \quad W(u) = u(1-u^2), \cr \dfrac{d}{dt}\displaystyle\int_0^L u~dx = \int_0^L\Delta_N\dfrac{\delta G}{\delta u}~dx = 0, \cr \dfrac{d}{dt}J(u) = \displaystyle\int_0^L\dfrac{\delta G}{\delta u}u_t~dx = \displaystyle\int_0^L \dfrac{\delta G}{\delta u}\Delta_N\dfrac{\delta G}{\delta u} ~ dx \le 0 \end{array} \]
  • 空間半離散化: \[ \begin{array}{c} \mathbf{u}_t = -L_h(\varepsilon^2 L_h\mathbf{u} + \gamma \mathbf{W}(\mathbf{u})) \quad\text{where}\quad W_m = u_m(1-(u_m)^2), \cr \dfrac{d}{dt}S(\mathbf{u}) = S\left(L_h\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}\right) = 0, \cr \dfrac{d}{dt}J_h(\mathbf{u}) = \left(\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}, \mathbf{u}_t\right)_h = \left(\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}, L_h\dfrac{\delta \mathbf{G}}{\delta\mathbf{u}}\right)_h \le 0 \end{array} \]
  • 時間離散化: \[ \begin{array}{c} \dfrac{\mathbf{u}^{n+1} - \mathbf{u}^n}{\tau} = -L_h\left(\varepsilon^2L_h\mathbf{u}^{n+1/2} + \gamma \mathbf{W}(\mathbf{u}^{n+1}, \mathbf{u}^n)\right) \quad\text{where}\quad W_m = u_m^{n+1/2}\left(1-\dfrac{(u_m^{n+1})^2 + (u_m^n)^2}{2}\right), \cr \dfrac{S(\mathbf{u}^{n+1}) - S(\mathbf{u}^n)}{\tau} = S\left(L_h\dfrac{\delta\mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^n)}\right) = 0, \cr \dfrac{J_h(\mathbf{u}^{n+1}) - J_h(\mathbf{u}^n)}{\tau} = \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, \dfrac{\mathbf{u}^{n+1}-\mathbf{u}^n}{\tau}\right)_h = \left(\dfrac{\delta \mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^{n})}, L_h\dfrac{\delta\mathbf{G}}{\delta(\mathbf{u}^{n+1}, \mathbf{u}^n)}\right)_h \le 0 \end{array} \]

また, 最後にニュートン法により計算を実行してみよう. つまり, 与えられた $\mathbf{u}^n$ に対し定められる関数 \[ \mathbf{f}_n(\mathbf{u}) = -L_h\left(\varepsilon^2L_h\dfrac{\mathbf{u} + \mathbf{u}^n}{2} + \gamma\mathbf{W}(\mathbf{u}, \mathbf{u}^n)\right) \] に対し, \[ \mathbf{u}^{n+1} - \tau\mathbf{f}_n(\mathbf{u}^{n+1}) - \mathbf{u}^n = \mathbf{0} \] の解 $\mathbf{u}^{n+1}$ をニュートン法で求める. その際, \[ \mathbf{F}_n(\mathbf{u}) = \mathbf{u} - \tau \mathbf{f}_n(\mathbf{u}) - \mathbf{u}^n \] のヤコビ行列 $D\mathbf{F}_n(\mathbf{u}) = I - \tau D\mathbf{f}_n(\mathbf{u})$ が必要になる. ここで, ヤコビ行列を計算する際には $\mathbf{u}^n$ は定数と思えば良いこと, および離散ラプラシアンに関する連鎖率 \[ D(L_h \mathbf{g}(\mathbf{u})) = L_h D(\mathbf{g}(\mathbf{u})) \] が成立することに注意すれば, \[ D\mathbf{f}_n(\mathbf{u}) = -\dfrac{\varepsilon^2}{2}L_h^2 - \dfrac{\gamma}{2}L_h + \dfrac{\gamma}{4}L_h D(\mathbf{T}(\mathbf{u})) \] である, ただし $\mathbf{T}(\mathbf{u})$ は第 $m$ 成分が $(u_m + u_m^n)((u_m)^2 + (u_m^n)^2)$ であるベクトルであり, 従って $D(\mathbf{T}(\mathbf{u}))$ は対角行列であり, その $(m, m)$ 成分 $d_m$ は \[ d_m = 3(u_m)^2 + 2(u_mu_m^n) + (u_m^n)^2 \] である. これを用いてヤコビ行列 $D\mathbf{F}_n(\mathbf{u}) = I - \tau D\mathbf{f}_n(\mathbf{u})$ を計算し, ニュートン法の反復計算 \[ \mathbf{u}^{n, k+1} = \mathbf{u}^{n, k} - D\mathbf{F}_n(\mathbf{u}^{n, k})^{-1}\mathbf{F}_n(\mathbf{u}^{n, k}) \] により $\mathbf{u}^{n+1}$ を (適当に打ち切ることで近似的に) 求めれば良い. 実際の数値計算結果を以下に掲載する:

import numpy as np 
import matplotlib.pyplot as plt 
from matplotlib.animation import FuncAnimation 

# Allen-Cahn equation: 
# u_t = eps * u_xx + mu * u(1-u^2) in [0, L]
# u(0, t) = 0, u(L, t) = 0 

# パラメータ 
eps: float = 0.1 
mu: float = 20.0

# 中心二階差分による空間離散化 
def Lap(u: np.ndarray, h: float) -> np.ndarray: 
    vec = np.empty_like(u) 
    vec[0] = (-2*u[0] + u[1]) / (h**2) 
    vec[-1] = (u[-2] - 2*u[-1]) / (h**2) 
    vec[1:-1] = (u[:-2] - 2*u[1:-1] + u[2:]) / (h**2) 
    return vec 

def W(u: np.ndarray) -> np.ndarray: 
    return u * (1 - u**2)

def f(u: np.ndarray, h: float) -> np.ndarray: 
    return eps**2 * Lap(u, h) + mu * W(u)

# 古典的ルンゲ=クッタ (４段陽的ルンゲ=クッタ)
def runge_kutta(u: np.ndarray, tau: float, h: float) -> np.ndarray:
    k1 = f(u, h)
    k2 = f(u + tau/2 * k1, h)
    k3 = f(u + tau/2 * k2, h)
    k4 = f(u + tau * k3, h)
    return u + tau/6 * (k1 + 2*k2 + 2*k3 + k4)

T: float = 0.3 
M: int = 300 
N: int = 5000

h: float = L/M 
tau = float = T/N

u0 = 0.6 * np.sin(3*np.pi*x/L) 
# 配列の初期化, 初期条件と境界条件の設定 
u = np.empty((M+1, N+1)) 
u[:, 0] = u0
u[0, :] = 0 
u[-1, :] = 0

# プロットの準備 
fig, ax = plt.subplots() 
ax.set_ylim([-1.1, 1.1])

# 初期条件のプロット 
line, = ax.plot(x, u[:, 0], color='tab:blue', linewidth=2.5)

カーン = ヒリアード方程式に対する離散変分導関数法: 


import numpy as np 
import matplotlib.pyplot as plt 
from matplotlib.animation import FuncAnimation 

# Allen-Cahn equation: 
# u_t = - (eps * u_xx + mu * u(1-u^2))_xx in [0, L]
# u(0, t) = 0, u(L, t) = 0 

# パラメータ 
eps: float = 0.1 
mu: float = 20.0

# 空間領域, 時間区間 
L: float = 1. 
T: float = 0.002 
M: int = 100 
N: int = 15000 
x = np.linspace(0, L, M+1) 
t = np.linspace(0, T, N+1) 
h: float = L/M 
tau: float = T/N 

# 離散ラプラシアン 
Lap: np.ndarray = (-2 * np.eye(M+1) + np.eye(M+1, k=1) + np.eye(M+1, k=-1)) / (h**2)
# 境界条件を考慮 
Lap[0, 1] = 2 / (h**2)
Lap[-1, -2] = 2 / (h**2)

# 関数 W
def W(u: np.ndarray, u_prev: np.ndarray) -> np.ndarray: 
    u_mid = (u + u_prev) / 2 
    return u_mid * (1 - (u**2 + u_prev**2) / 2)
# 離散化された右辺 
def f(u: np.ndarray, u_prev: np.ndarray) -> np.ndarray: 
    u_mid = (u + u_prev) / 2 
    return -Lap @ (eps**2 * Lap @ u_mid + mu * u_mid * (1 - (u**2 + u_prev**2) / 2))
# ヤコビ行列 
def df(u: np.ndarray, u_prev: np.ndarray) -> np.ndarray: 
    DT = np.diag(3*(u**2) + 2*u*u_prev + u_prev**2)
    return -(eps**2)/2 * Lap @ Lap - mu/2 * Lap + mu/4 * Lap @ DT


# ニュートン法
def newton(x_prev: np.ndarray, tau: float, tol: float = 1e-6, max_iter: int = 30) -> np.ndarray: 
    x = x_prev 
    for _ in range(max_iter): 
        F = x - tau*f(x, x_prev) - x_prev 
        DF = np.eye(M+1) - tau*df(x, x_prev)
        x = x - np.linalg.solve(DF, F)
    if np.linalg.norm(np.linalg.solve(DF, F)) < tol:
       return x
    raise ValueError('Newton method did not converge.')

# 初期条件 (境界条件を満たすものを指定)
u0 = 0.7 * np.cos(3*np.pi*x/L) 
# 配列の初期化, 初期条件の設定 
u = np.empty((M+1, N+1)) 
u[:, 0] = u0

# プロットの準備 
fig, ax = plt.subplots()

line, = ax.plot(x, u[:, 0], color='tab:blue')

def update(frame): 
    line.set_data(x, u[:, frame]) # 更新された u を入力 
    return 

# 計算 
for n in range(N): 
    u[:, n+1] = newton(u[:, n], tau, h)
