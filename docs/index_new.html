はじめに

力学系 (dynamical system) とは, あるシステムの「現在の状態」が与えられたとき, 時間経過による状態変化の法則を記述する数学的な枠組みである. この資料では, 力学系の性質や解の挙動に関する基本的な概念を導入し, 特に 非線形力学系 の解の複雑な挙動を調べるためのテクニックを紹介する.

力学系の簡単な具体例として, 物体の自由落下を表現する数理モデルを考えよう. いま, $t$ を時刻, $x(t)$ を鉛直上向きを正とした, 時刻 $t$ における物体の位置, $g\gt0$ を重力加速度定数とする. このとき, \[ x''(t) = -g \] という 常微分方程式 を考えると, この常微分方程式は "物体の自由落下" というシステムの, 状態の時間変化を記述する法則であると解釈できる. 実際に, $v(t) = x'(t)$ が速度を表すことに注意し, 時刻 $t=0$ における 初期値 を $x(0) = x_0$ および $v(0) = v_0$ により与えると, 上の常微分方程式は \[ \mathbf{x}' = \begin{pmatrix} x' \cr v' \end{pmatrix} = \begin{pmatrix} v \cr -g \end{pmatrix}, \qquad \mathbf{x}(0) = \begin{pmatrix} x(0) \cr v(0) \end{pmatrix} = \begin{pmatrix} x_0 \cr v_0 \end{pmatrix} \] という 常微分方程式系 と同一視でき, これは確かに『$x, v$ からなるシステムの状態の時間変化が常微分方程式系により記述されている』という力学系である. ここで, 位置 $x$ だけでは, その後の状態の時間変化を決定できないことに注意してほしい (ある時刻で位置が同じであったとしても, 速度が異なっていればその後の運動が異なる). このシステムの状態を表すために必要な変数は $\mathbf{x} = \begin{pmatrix}x \cr v\end{pmatrix}$ であり, このような変数は 状態変数 と呼ばれる. なお, この力学系の解は \[ \mathbf{x}(t) = \begin{pmatrix} x(t) \cr v(t) \end{pmatrix} = \begin{pmatrix} x_0 + v_0 t - \dfrac{1}{2}gt^2 \cr v_0 - gt \end{pmatrix} \] という形で明示的に表すことができる. 特に, 時刻 $t=0$ における 初期条件 $x(0) = x_0, v(0) = v_0$ を与えることで, その後の状態 $x(t), v(t)$ を決定できる.

このように, 時間を連続的な変数 $t$ として状態の変化を考える力学系を 連続力学系 (continuous dynamical system) という. 特に, 常微分方程式系 \[ \mathbf{x}'(t) = \mathbf{f}(\mathbf{x}(t)) \] は連続力学系を与える代表的な方法である. また, このように右辺が時刻 $t$ に陽に依存しない系を 自励系 (autonomous system) という (一般には, $\mathbf{x}' = \mathbf{f}(t, \mathbf{x})$ のような 非自励系 を考えることもできる).

このことに関連して, いくつかの用語を導入しておこう. まず, 常微分方程式系 $\mathbf{x}' = \mathbf{f}(\mathbf{x})$ の解が各初期値に対して一意に存在するならば, 時刻 $s$ における状態 $\mathbf{x}(s)$ が与えられたとき, そこから時間 $t$ だけ経過した後の状態 $\mathbf{x}(s+t)$ が一意に定まる. この時間発展を写像 $\Phi_t$ を用いて \[ \mathbf{x}(s+t)=\Phi_t(\mathbf{x}(s)) \] と表す. 特に, 解がすべての時刻 $t\in\mathbb{R}$ に対して存在するとき, この 時間発展写像 $\Phi_t$ の族 \[ \{\Phi_t:t\in\mathbb{R}\} \] を フロー (flow) という. なお, 時間発展写像は \[ \left\{\begin{array}{rl} \Phi_0 &= \operatorname{id}_X, \cr \Phi_{t+s} &= \Phi_t\circ\Phi_s \end{array}\right. \] を満たすことが重要である (後者は, 『時間 $s$ だけ進めた後に, 時間 $t$ だけ進める』ことと, 『はじめから $t+s$ だけ時間を進める』ことが同じであることを意味している).

また, 各時間発展写像 \[ \Phi_t:X\to X \] の定義域および値域である $X$ は, システムが取り得るすべての状態からなる空間であり, 相空間 (phase space) もしくは 状態空間 (state space) と呼ばれる. システムの各状態 $\mathbf{x}$ は相空間 $X$ 上の点として表される. したがって, 与えられた初期条件 $\mathbf{x}(0) = \mathbf{x}_0$ に対する常微分方程式系の解 $\mathbf{x}(t)$ は, 点 $\mathbf{x}_0$ から出発し時間経過により相空間 $X$ 上を動く点と思ってプロットすることができる. このとき, 相空間上に描かれる曲線 \[ \{\mathbf{x}(t):t\in\mathbb{R}\} \] を (与えられた初期条件 $\mathbf{x}(0) = \mathbf{x}_0$ に対する) 軌道 (orbit) という.

自励系 $\mathbf{x}'(t) = \mathbf{f}(\mathbf{x})$ は相空間上を動く点 $\mathbf{x}(t)$ の速度を表すため, $\mathbf{f}(\mathbf{x})$ は相空間上の点 $\mathbf{x}$ を, 「状態 $\mathbf{x}$ が時間経過によりどの方向に, どの速さで進むか」を表すベクトルに対応させる ベクトル値関数 (ベクトル場) となっている. 特に自励系では, ある状態 $\mathbf{x}$ における速度 $\mathbf{x}' = \mathbf{f}(\mathbf{x})$ が現在の状態 $\mathbf{x}$ だけによって決まる (時刻そのものには依存しない). そのため, ベクトル場 $\mathbf{f}$ の相空間全体における構造を調べれば, 解を明示的に求めることなく, 解の時間変化の様子を調べることができる. これは自励系の (非自励系と比較して) 著しいメリットである.

一方で, 時間を連続的に変化する変数としてではなく, \[ n = 0, 1, 2, \dots \] のような 離散的 な変数として考えることもできる. このように離散的な時間に沿って状態が変化する力学系を 離散力学系 (discrete dynamical system) という. 例えば, 相空間 $X$ 上の写像 \[ F:X\to X \] が与えられたとき, \[ \mathbf{x}_{n+1} = F(\mathbf{x}_n) \] によって状態の時間発展を定めることができる. 初期状態 $\mathbf{x}_0$ が与えられれば, \[ \mathbf{x}_1 = F(\mathbf{x}_0),\qquad \mathbf{x}_2 = F(\mathbf{x}_1) = F^2(\mathbf{x}_0),\qquad\dots \] となるため, 一般に \[ \mathbf{x}_n = F^n(\mathbf{x}_0) \] と表すことができる. したがって離散力学系においても, 現在の状態 $\mathbf{x}_n$ が与えられれば, 写像 $F$ という法則によって次の状態 $\mathbf{x}_{n+1}$ が定まり, さらにそれを繰り返すことでその後のすべての状態が決定される.

連続力学系における時間発展写像 $\Phi_t$ と, 離散力学系における反復写像 $F^n$ はよく似た性質を持つ. 実際に, \[ \Phi_{t+s} = \Phi_t\circ\Phi_s \] に対応して, \[ F^{n+m} = F^n\circ F^m \] が成り立つ. したがって, 連続力学系と離散力学系は一見すると異なるものであるが, どちらも『ある状態を時間の経過に従って別の状態へ移す』という共通の構造を持っている. また, 連続力学系のフロー $\Phi_t$ に対して時間間隔 $\tau\gt0$ を固定し, \[ F=\Phi_{\tau}, \qquad \mathbf{x}_n = \mathbf{x}(n\tau) = \Phi_{n\tau}(\mathbf{x}_0) \] とおくことにより, \[ \mathbf{x}_{n+1} = F(\mathbf{x}_n) \] という離散力学系を得ることができる. このように, 連続時間の力学系を一定の時間間隔ごとに観察することで離散力学系が自然に現れるという, 両者の密接な関係が見える.

さて, 力学系が自励系であったとしても, その解を解析的に求めることができるとは限らない (いくつかの微分方程式には解の公式が知られているが, そのようなものはごく一部に限られる). 特に非線形力学系では, 解を明示的な数式として表すことは一般には困難である. そのため, 力学系理論では解を明示的に求めることよりも, さまざまな初期値から出発した解の挙動を調べることで, 解全体の構造を理解することが重要となる. この目的のために, 平衡点 とその 安定性, 周期軌道, 不変集合, ポアンカレ写像, 分岐 など, 様々な概念や解析手法が導入される.

力学系の理論は古くから発展してきたものであるが, 一方でコンピュータの登場以降は力学系の解を近似的に求め, その挙動を可視化することも容易になった. 特に非線形力学系の解として, カオス (chaos) に代表される非常に複雑な振る舞いを観察できるようになったことは, 力学系の研究の発展にも大きな役割を果たしてきた. ただし, 数値計算によって軌道を描くことができたとしても, それだけで力学系の性質が理解されたことにはならない. 特に, 長時間にわたる解の挙動や安定性, 周期軌道の存在, カオスなど, 数値計算によって得られた解の挙動を理解, 説明するために, 力学系における様々な概念は欠かせないものである.

この資料では, 特に 非線形力学系 の解析を最終的な目標として, そのために必要となる基本的な概念を順に導入する. まずは比較的取り扱いやすい線形力学系を題材として, 相空間, 軌道, 平衡点, 安定性などの基本概念を具体例を通じて理解する. その後, 非線形力学系へと進み, 線形系との違いや非線形性によって生じる新たな現象について考える.

補足

この資料の内容に関連するものの, 詳細については言及しないものについて以下に列挙する.

$\mathbb{R}^d$ 上のユークリッドノルム (ベクトルのノルム) を \[ \|\mathbf{v}\| = \sqrt{\sum_{k=1}^d v_k^2} \] と表記する. また, 対応する $\mathbb{R}^{d\times d}$ 上のノルム (行列ノルム) を \[ \|A\| = \sup_{\mathbf{v}\in\mathbb{R}^d,\ \mathbf{v}\neq \mathbf{0}} \dfrac{\|A\mathbf{v}\|}{\|\mathbf{v}\|} \] と定義する.

  1. $\|A\mathbf{v}\| \le \|A\|\|\mathbf{v}\|\quad \text{for all}\quad \mathbf{v}\in\mathbb{R}^d$, $A\in\mathbb{R}^{d\times d}$.
  2. $\|AB\| \le \|A\|\|B\|\quad \text{for all}\quad A, B\in\mathbb{R}^{d\times d}$.
  1. 行列ノルムの定義より明らか.
  2. 1. より \[ \begin{array}{rl} \|AB\| &= \displaystyle\sup_{\mathbf{v}\in\mathbb{R}^d,\ \mathbf{v}\neq \mathbf{0}}\dfrac{\|AB\mathbf{v}\|}{\|\mathbf{v}\|} \cr &\le \displaystyle\sup_{\mathbf{v}\in\mathbb{R}^d,\ \mathbf{v}\neq \mathbf{0}}\dfrac{\|A\|\|B\mathbf{v}\|}{\|\mathbf{v}\|} \cr &\le \|A\|\|B\|. \end{array} \]

関数 $u$, $\beta$ は区間 $I = [a, b)$ 上で連続とする, ただし $a\lt b\le \infty$ とする. また, $u$ は区間 $I$ の内部 $\mathring{I}$ で微分可能であるとする. このとき, \[ u'(t)\le \beta(t) u(t) \quad \text{for all}\quad t\in \mathring{I} \implies u(t) \le u(a)\exp\left(\int_a^t \beta(s)~ds\right)\quad\text{for all}\quad t\in I \] が成立する.

もしも $\beta$ が関数ではなく定数ならば, 任意の $t\in\mathring{I}$ に対し $u'(t) \le \beta u(t)$ が成立するとき, 任意の $t\in I$ に対し \[ \begin{array}{rl} \left[u(s)e^{-\beta s}\right]_a^t &= \displaystyle\int_a^t \dfrac{d}{ds}(u(s)e^{-\beta s})~ds \quad (\because \text{微積分学の基本定理}) \cr &= \displaystyle\int_a^t e^{-\beta s}\underbrace{(u'(s) - \beta u(s))}_{\le 0}~ds \cr &\le 0 \end{array} \] より \[ \left[u(s)e^{-\beta s}\right]_a^t = u(t)e^{-\beta t} - u(a)e^{-\beta a} \le 0 \] が得られ, さらに式変形して \[ u(t) \le u(a)e^{\beta(t-a)}\quad\text{for all}\quad t\in I \] が得られるが, Grönwall の不等式はこれの一般化であると思える.

上の 注意 と同様の式変形により, 与えられた条件の下で \[ \begin{array}{rl} \displaystyle\left[u(s)\exp\left(-\int_a^s\beta(\xi)~d\xi\right)\right]_a^t &= \displaystyle\int_a^t \dfrac{d}{ds}u(s)\exp\left(-\int_a^s\beta(\xi)~d\xi\right)~ds \cr &= \displaystyle\int_a^t \exp\left(-\int_a^s\beta(\xi)~d\xi\right)\underbrace{\left(u'(s) - \beta(s)u(s)\right)}_{\le 0}~ds \cr &\le 0 \end{array} \] より \[ u(t)\exp\left(-\int_a^t\beta(\xi)~d\xi\right) - u(a)\exp\underbrace{\left(-\int_a^a\beta(\xi)~d\xi\right)}_{=0} \le 0 \] が得られ, さらに式変形して \[ u(t) \le u(a)\exp\left(\int_a^t\beta(\xi)~d\xi\right)\quad\text{for all}\quad t\in I \] が得られる.

与えられた $\mathbf{x}_0\in\mathbb{R}^d$ および $r\gt0$ に対し, $\mathbf{f}: \overline{B}_r(\mathbf{x}_0)\to\mathbb{R}^d$ がリプシッツ連続であるとする. このとき, 常微分方程式系 \[ \left\{\begin{array}{rl} \mathbf{x}' &= \mathbf{f}(\mathbf{x}) \cr \mathbf{x}(0) &= \mathbf{x}_0 \end{array}\right. \] について, ある $\delta\gt 0$ が存在し, 区間 $[-\delta, \delta]$ 上の関数 $\mathbf{x}(t)$ で, 上の常微分方程式系の解となるものがただ一つ存在する.

ここでは Picard の逐次近似法による構成を述べておく: 上の初期値問題は \[ \mathbf{x}(t) = \mathbf{x}_0 + \int_0^t \mathbf{f}(\mathbf{x}(s))~ds \] という積分方程式と同値なので, この近似関数列を \[ \left\{\begin{array}{rl} \mathbf{x}^0(t) &= \mathbf{x}_0, \cr \mathbf{x}^{i+1}(t) &= \mathbf{x}_0 + \displaystyle\int_0^t\mathbf{f}(\mathbf{x}^i(s))~ds \end{array}\right. \] と構成する.

まず, 適切に $\delta$ を定めれば, これにより構成される $\mathbf{x}^{i}(t)$ が区間 $[-\delta, \delta]$ 上で well-defined であることを確認しよう. $\mathbf{f}$ は閉球 $\overline{B}_r(\mathbf{x}_0)$ 上でリプシッツ連続, 特に連続であるから, \[ \max_{\mathbf{x}\in\overline{B}_r(\mathbf{x}_0)} \|\mathbf{f}(\mathbf{x})\| \lt \infty \] であることに注意して, \[ \delta = \dfrac{r}{\displaystyle\max_{\mathbf{x}\in\overline{B}_r(\mathbf{x}_0)} \|\mathbf{f}(\mathbf{x})\| } \] と定める. いま, 任意の $t\in [-\delta, \delta]$ に対して $\mathbf{x}^i(t)\in \overline{B}_r(\mathbf{x}_0)$ と仮定すると, \[ \|\mathbf{x}^{i+1}(t) -\mathbf{x}_0\| = \left\|\int_0^t \mathbf{f}(\mathbf{x}^i(s))~ds \right\| \le |t|\max_{\mathbf{x}\in \overline{B}_r(\mathbf{x}_0)}\|\mathbf{f}(\mathbf{x})\| = r \] なので, 任意の $t\in [-\delta, \delta]$ に対し $\mathbf{x}^{i+1}(t)\in \overline{B}_r(\mathbf{x}_0)$ が得られる. 従って, 帰納的に全ての $\mathbf{x}^i$ が区間 $[-\delta,\delta]$ 上で $\overline{B}_r(\mathbf{x}_0)$, すなわち $\mathbf{f}$ の定義域に含まれることがわかった.

次に, Picard の逐次近似 $\mathbf{x}^i$ がある関数 $\mathbf{x}$ に一様収束すると仮定し, 常微分方程式系の解の存在を示そう. 仮定と $\mathbf{f}$ がリプシッツ連続であることから $\mathbf{f}(\mathbf{x}^i)$ は $\mathbf{f}(\mathbf{x})$ に一様収束する. これを用いると \[ \begin{array}{rl} \mathbf{x}(t) &= \displaystyle\lim_{i\to\infty}\mathbf{x}^{i+1}(t) \cr &= \mathbf{x}_0 + \displaystyle\lim_{i\to\infty}\int_0^t\mathbf{f}(\mathbf{x}^i(s))~ds \cr &= \mathbf{x}_0 + \displaystyle\int_0^t\lim_{i\to\infty}\mathbf{f}(\mathbf{x}^i(s))~ds \quad(\because\text{$\mathbf{f}(\mathbf{x}^i)$ の一様収束性}) \cr &= \mathbf{x}_0 + \displaystyle\int_0^t\mathbf{f}\left(\lim_{i\to\infty}\mathbf{x}^i(s)\right)~ds \quad(\because\text{$\mathbf{f}$ の連続性}) \cr &= \mathbf{x}_0 + \displaystyle\int_0^t \mathbf{f}(\mathbf{x}(s))~ds \end{array} \] となるため, この $\mathbf{x}(t)$ が解である.

また, 解が存在するならば一意であることは Grönwall の不等式を用いて示すことができる. 同じ初期値 $\mathbf{x}_0$ を持つ異なる $2$ つの解 $\mathbf{x}(t)$, $\mathbf{y}(t)$ が区間 $[-\delta,\delta]$ 上に存在すると仮定する. まず $t\in[0,\delta]$ のときは \[ u(t) = \|\mathbf{x}(t)-\mathbf{y}(t)\|^2 \] とおくと, \[ \begin{array}{rl} u'(t) &= 2 \left(\mathbf{x}(t)-\mathbf{y}(t)\right)\cdot \left(\mathbf{x}'(t)-\mathbf{y}'(t) \right) \cr &= 2 \left(\mathbf{x}(t)-\mathbf{y}(t)\right) \cdot \left(\mathbf{f}(\mathbf{x}(t)) - \mathbf{f}(\mathbf{y}(t)) \right) \cr &\le 2 \|\mathbf{x}(t)-\mathbf{y}(t)\| \, \left\|\mathbf{f}(\mathbf{x}(t)) -\mathbf{f}(\mathbf{y}(t))\right\|\\ &\le 2L \|\mathbf{x}(t)-\mathbf{y}(t)\|^2\\ &= 2Lu(t) \end{array} \] が得られる, ただし $L$ はリプシッツ定数である. また, \[ u(0) = \|\mathbf{x}_0-\mathbf{x}_0\|^2 = 0 \] であることに注意すると, Grönwall の不等式より \[ 0\le u(t) \le u(0)e^{2Lt} = 0 \] となり, $\mathbf{x}(t)=\mathbf{y}(t)$ が得られるため矛盾する. また, $t\in[-\delta, 0]$ のときは $\widetilde{\mathbf{x}}(t)=\mathbf{x}(-t)$ などと置くことで, 上と同じ議論からやはり解の一意性が証明される.

あとは $\mathbf{f}$ のリプシッツ連続性から Picard 逐次近似の一様収束性を示せば良い. 詳細は省略するが, (必要ならば $\delta$ をリプシッツ定数に応じてさらに小さく取り直し) Banach の不動点定理を用いるなどして証明することができる.

上の定理が適用 できない 例として \[ x' = 2\sqrt{|x|},\quad x(0) = 0 \] という常微分方程式を考えてみる. 右辺は $x=0$ を含む開区間上で (連続ではあるが) リプシッツ連続では無い. この問題は \[ x_1(t) = 0,\quad x_2(t) = \left\{\begin{array}{rl} 0 & \text{if }t\le 0, \cr t^2 & \text{if }t\gt 0 \end{array}\right. \] のように少なくとも $2$ つ解を持つことが確認できるため, 解が存在するが一意では無いような例となっている.

解の一意存在は, 初期状態からその後の状態が一意に定まるという力学系の考え方を保証するために重要なものである.

Picard の逐次近似は, 常微分方程式系の 時間局所解 の一意存在を保証するが, 一方で解がすべての時刻まで存在すること, すなわち 時間大域解 の一意存在を保証するものではないことに注意. 例えば, \[ \left\{\begin{array}{rl} x' &= x^2, \cr x(0) &= x_0\gt 0 \end{array}\right. \] は (上の定理が適用可能であり, 確かに) $t\lt 1/x_0$ では \[ x(t) = \dfrac{x_0}{1-x_0t} \] というただ一つの解を持つ. しかしながら, この解は $t = 1/x_0$ で 爆発 (blow up) し, 以降の時刻に解を延長することができない.

この資料では, 時間発展をフローとして扱うことができる力学系の例として, 時間大域的に一意解を持つ常微分方程式系を考えたいが, そのためには解が有限時間で爆発しないことを保証するための条件が必要となる. 例えば, $\mathbf{f}:\mathbb{R}^d\to\mathbb{R}^d$ が大域的にリプシッツ連続であれば, 任意の初期値に対する解は時間大域的に一意に存在することが知られている.

なお, 上の例では $f: \mathbb{R}\to\mathbb{R}$ として $f(x) = x^2$ を考えているが, これは局所リプシッツ連続ではあるものの大域的にリプシッツ連続ではない.
